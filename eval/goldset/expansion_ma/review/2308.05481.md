## 초록+서론 한글 번역
데이터베이스 관리자(DBA)는 데이터 가용성·성능·신뢰성을 보장하기 위해 DB 시스템을 관리·유지·최적화하는 핵심 역할을 한다. 그러나 수백만 개의 클라우드 DB 인스턴스처럼 대규모 인스턴스를 관리하는 것은 어렵고 지루하다. 최근 LLM은 가치 있는 문서를 이해하고 합리적 답변을 생성할 잠재력을 보였다. 이에 저자들은 텍스트 소스로부터 DB 유지보수 경험을 지속적으로 습득하고, 대상 DB에 대해 합리적이고 근거 있는 적시 진단·최적화 조언을 제공하는 LLM 기반 DBA인 D-Bot을 제안한다. 이 논문은 (i) 문서·도구로부터 유지보수 지식 탐지, (ii) 근본원인 분석을 위한 tree-of-thought 추론, (iii) 다수 LLM 간 협업 진단을 포함하는 LLM 중심 DB 유지보수 프레임워크를 제시한다.

서론: 대부분 기업이 여전히 DBA에 의존하지만, DBA 양성에 오랜 시간이 걸리고(제품 1개 문서가 1만 페이지 이상), 대규모 인스턴스를 감당할 DBA를 충분히 확보하기 어려우며, 긴급 상황(특히 모듈 간 상관 이슈)에 적시 대응이 어렵다. 기존 반자동 DB 도구는 경험규칙·소규모 ML 모델 기반이라 텍스트 처리력이 약하고 문서를 활용하지 못하며, 시나리오 변화에 유연하지 못하고, DBA처럼 이상의 근본원인을 추론하지 못한다. 저자들의 비전은 문서로부터 지치지 않고 배우는 "인간을 넘어서는 DBA"로, (1) 문서에서 경험 학습, (2) DB와 상호작용해 상태 지표 획득, (3) 비정상 지표로 근본원인 추론, (4) 적절한 도구 호출로 최적화 조언을 자동 수행한다. 세 가지 도전과제는 (1) 문서로부터 경험 학습(긴 문서·형식 다양), (2) DB와 상호작용하는 추론(환각 문제 완화), (3) 다수 LLM 간 커뮤니케이션 메커니즘(한 LLM은 준최적에 빠질 수 있어 여러 LLM이 협업). D-Bot은 문서를 청크로 나눠 요약해 경험 지식으로 변환하고, 작업 서술 형식을 반복 생성·평가하며, 매칭 알고리즘으로 외부 도구를 선택·사용하고, tree-of-thought 전략으로 실패 시 이전 단계로 되돌아가며, 사전 정의된 환경 설정 하에 다수 LLM이 토론식 커뮤니케이션으로 협업 진단을 수행한다.
