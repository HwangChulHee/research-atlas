# 2504.12330 — HM-RAG: Hierarchical Multi-Agent Multimodal Retrieval Augmented Generation

**한 줄 핵심**: 질의 분해 에이전트 + 다중소스 검색 에이전트(벡터·그래프·웹) + 일관성 투표 기반 결정 에이전트로 구성된 3계층 다중 에이전트 멀티모달 RAG 프레임워크(HM-RAG)를 제안한다.

**keep/drop**: keep — 계층적 다중 에이전트 협업(분해→병렬검색→결정 투표)이 방법의 본질인 다중 에이전트 RAG 방법 논문.

**builds_on 초안**: [] (근거: 대비 대상은 single-agent/single-modal RAG(baseline). RAG는 D4 범주어 제외. GraphRAG/LightRAG는 배경으로 언급되나 HM-RAG가 그 위에서 확장한 것이 아니라 대안 아키텍처 → boundary 처리)

**경계 플래그**: GraphRAG, LightRAG — "그래프 기반 검색 프레임워크로 대표됨"으로 명명 인용되고 그 트레이드오프(세밀 정보 손실)를 한계로 지적하나, HM-RAG는 그 위에 쌓기보다 벡터·그래프·웹을 병렬 통합하는 다른 아키텍처라 계보 포함 여부 애매. D2(한계→개선)로 볼지 flag.

## 초록+서론 한글 번역
RAG는 외부 지식으로 LLM을 보강하지만, 기존 단일 에이전트 RAG는 이질적 데이터 생태계에 걸친 협조적 추론을 요하는 복잡 질의 해결에 근본적 한계가 있다. 본 논문은 구조화·비구조화·그래프 기반 데이터에 걸친 동적 지식 종합을 위해 협업 지능을 개척하는 새로운 계층적 다중 에이전트 멀티모달 RAG 프레임워크 HM-RAG를 제안한다. 3계층 아키텍처의 특화 에이전트: (1) 복잡 질의를 의미 인식 질의 재작성과 스키마 기반 컨텍스트 증강으로 맥락 일관 하위과제로 분해하는 분해 에이전트, (2) 벡터·그래프·웹 DB용 플러그앤플레이 모듈로 병렬·모달리티별 검색을 수행하는 다중소스 검색 에이전트, (3) 일관성 투표로 다중소스 답을 통합하고 전문가 모델 정제(Expert Model Refinement)로 불일치를 해소하는 결정 에이전트. 텍스트·그래프관계·웹 증거를 결합해 포괄적 질의 이해를 달성하며, ScienceQA·CrisisMMD 벤치마크에서 baseline 대비 답변 정확도 12.95%, 질의 분류 정확도 3.56% 향상, 제로샷 SOTA를 달성한다.

서론: 이질적 소스에서 관련 정보를 효율적으로 검색하는 능력은 현대 정보 시스템의 기둥이 되었다. 텍스트·이미지·벡터·웹 콘텐츠를 통합하는 멀티모달 검색 시스템은 전자상거래·의료·과학 연구 전반에서 필수적이나, 질의 유형의 다양성·데이터 포맷 이질성·검색 목적 다양성 때문에 여전히 큰 난제다. 검색 기술은 역사적으로 단일 모달 아키텍처 중심으로 발전했다. 텍스트 기반 RAG는 견고한 성능을 보였으나 시각 콘텐츠를 다루지 못해 이미지 기반 RAG가 등장했다. 그러나 현재 멀티모달 구현은 시각 콘텐츠 처리는 뛰어나도 시각-텍스트 간 일관된 교차모달 상관을 세우지 못하는 병목이 있다. 최근 GraphRAG, LightRAG로 대표되는 그래프 기반 검색 프레임워크가 지식 그래프로 텍스트 상호의존을 모델링하고 멀티모달 입력으로 확장되었으나, 고수준 모달리티 상호작용은 잘 잡되 세밀한 정보 충실도를 희생하는 트레이드오프가 있다. 또한 텍스트(세밀한 의미)와 시각(공간 맥락)의 상보적 강점을 조화시키는 것도 난제로, 모달리티 고립이 이질적 데이터 환경에서 정보 손실 위험을 낳는다. 이를 해결하기 위해 저자들은 협조적 다중 에이전트 협업으로 멀티모달 검색을 강화하는 HM-RAG를 도입한다. 3계층 아키텍처에서 분해 에이전트가 질의 의도를 분석·재작성하고, 다중소스 검색 에이전트가 벡터·그래프·웹에 걸쳐 병렬 검색하며, 결정 에이전트가 도메인 특화 검증으로 후보 응답을 종합·정제한다. 기여: 모듈형 계층 프레임워크, 다중소스 플러그앤플레이 검색 통합, 전문가 유도 정제, ScienceQA·CrisisMMD SOTA 실증.
