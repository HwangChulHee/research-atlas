# 2310.01444 — Adapting LLM Agents Through Communication (Learning through Communication, LTC)

**한 줄 핵심**: 언어적 피드백과 비언어적 보상신호를 하나의 universal buffer에 저장하고 탐색·갱신 반복 파이프라인으로 LLM 에이전트를 온라인 학습시키는 프레임워크 LTC로, 단일/멀티에이전트용 통신 패턴(monologue, dialogue, teacher-student)을 제공한다.

**keep/drop**: keep — 멀티에이전트 통신 패턴(multi-agent dialogue/competition/teacher-student)이 프레임워크의 핵심 구성으로, 에이전트 간 상호작용을 통한 협업 학습이 방법의 본질. (경계 플래그 참조)

**builds_on 초안**: [] (근거: LTC가 결합·비교하는 Instruction Fine-tuning(IFT), ReAct-Tuning, CoT-Tuning은 학습 baseline으로 D-규칙상 점수비교 baseline 제외. PPO는 D1 옵티마이저 제외. universal buffer·통신 패턴은 self-정의. 계보로 딛은 명명된 기법/시스템 없음.)

**경계 플래그**: LTC는 single-agent(ALFWorld)와 multi-agent(HotpotQA/Chameleon/teacher-student)를 모두 포괄하는 학습 프레임워크로, 멀티에이전트 협업이 유일 본질이 아니라 여러 통신 패턴 중 하나 — keep이지만 '멀티에이전트가 본질' 경계에 걸침.

## 초록+서론 한글 번역
최근 LLM의 발전으로 LLM 에이전트 가능성이 부각되었다. 언어적 피드백과 비언어적 보상신호 양쪽으로 이 에이전트들을 학습시키기 위해, 저자들은 Learning through Communication(LTC)을 도입한다. 모든 피드백을 저장하는 universal buffer와, LLM 에이전트가 주어진 환경에서 정책을 탐색·갱신하게 하는 반복 파이프라인을 설계한다. 다양한 작업의 에이전트 상호작용을 buffer로 담기 위해 단일/멀티에이전트 환경에 맞춘 다양한 통신 패턴을 도입한다. ALFWorld(단일), HotpotQA(멀티 협업), Chameleon(멀티 경쟁), GSM8k(멀티 교사-학생) 네 데이터셋에서 지도 명령튜닝 baseline 대비 3.6%~12% 향상한다.

서론: LLM 발전으로 인간형 LLM 에이전트가 가능해졌고, 프롬프팅 방법 설계 외에도 언어적 피드백(IFT로 처리)과 비언어적 보상신호(인간 선호 정렬)로 에이전트를 학습시키는 연구가 활발하다. 그러나 기존 방법은 이질적 피드백을 부분적으로만 활용한다(예: 보드게임 롤플레잉에서 언어 데이터는 IFT에, 보상신호는 데이터 필터링 기준으로만 쓰이고 RL 목표로는 안 쓰임). 이 격차를 메우기 위해 LTC를 제안한다. universal buffer와 반복 파이프라인을 두며, 각 반복은 (1) 탐색: 에이전트가 환경·타 에이전트와 상호작용해 궤적(언어)과 보상신호(비언어)를 buffer에 수집, (2) 갱신: buffer 데이터로 모델 갱신(언어모델링 손실 + PPO 손실 결합)으로 구성된다. 세 가지 통신 패턴을 설계한다: (1) Single-agent Monologue, (2) Multi-agent Dialogue(다중 에이전트가 서로·외부 도구와 상호작용), (3) Teacher-student Dialogue(교사 에이전트가 피드백·보상 제공). 대표 데이터셋 실험에서 LTC는 baseline을 일관되게 능가하며, HotpotQA에서 IFT 대비 5%(EM) 향상, Llama-7B 기반 에이전트가 9배 큰 PaLM-62B의 ReAct-Tuning보다 근소 우위, GSM8k에서 CoT-Tuning 대비 3.6% 향상한다.
