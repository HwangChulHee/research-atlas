## 초록+서론 한글 번역
소프트웨어 시스템의 유지·확장은 효과적 코드 리팩터링에 크게 의존하나, 이 과정은 개발자가 기존 코드베이스를 신중히 분석하고 새 결함 도입을 막아야 하는 노동집약적 작업이다. 최근 LLM으로 리팩터링을 자동화하려는 시도가 있었으나, 현 솔루션들은 범위가 제한적이고 코드 컴파일 가능성·테스트 통과를 보장하는 메커니즘이 없다. 본 연구는 메서드 수준 리팩터링을 자동화하는 포괄적 LLM 에이전트 기반 프레임워크 MANTRA를 제안한다. MANTRA는 Context-Aware Retrieval-Augmented Generation, 조율된 Multi-Agent Collaboration, Verbal Reinforcement Learning을 통합해 인간의 리팩터링 의사결정을 모사하면서 코드 정확성·가독성을 보존한다. 10개 대표 Java 프로젝트에서 추출한 703개 "순수 리팩터링" 사례로 6개 최빈 리팩터링 연산을 다룬 실증 연구에서, MANTRA는 베이스라인 LLM(RawGPT)의 8.7%(61/703) 대비 82.8%(582/703)의 컴파일·테스트 통과 성공률을 달성했다. IntelliJ의 LLM 리팩터링 도구(EM-Assist) 대비 Extract Method 변환에서 50% 개선을 보였고, 37명 전문 개발자 사용성 연구에서 MANTRA의 리팩터링이 인간 작성 코드만큼 읽기 쉽고 재사용 가능하다고 평가되었다.

리팩터링은 코드의 동작을 바꾸지 않으면서 전반 설계·구조를 개선하는 과정이다. 유지보수성을 높이고 기능 확장을 용이하게 하나, 시간·노력 때문에 많은 개발자가 주저한다. 연구자와 IDE 개발자(Eclipse, IntelliJ IDEA 등)는 자동 리팩터링 기법을 제안해 왔다. 예컨대 Tsantalis and Chatzigeorgiou는 Feature Envy·Long Method 같은 코드 스멜을 탐지해 리팩터링을 적용하는 JDeodorant를 제안했고, WitchDoctor는 코드 변경이 사전 정의 명세를 촉발하는지 모니터링해 리팩터링을 추천한다. 이 도구들의 공통 특징은 사전 정의 규칙·메트릭 기반이라는 점이며, 프로젝트 도메인 구조에 대한 깊은 이해가 없어 개발자 스타일의 리팩터링을 만들지 못해 실사용 수용도가 낮다. 최근 LLM 연구는 복잡한 프로그래밍 과제 처리에서 큰 잠재력을 보였고, 여러 연구가 LLM 리팩터링을 탐구했으나 대부분 단순 프롬프트 기반 생성에 의존하고, 제한된 리팩터링 유형만 다루며, 컴파일·테스트 실행 검증이 부족하다. 또한 LLM의 self-reflection·self-improvement 능력을 충분히 활용하지 못해 인간 수준에 못 미친다. 본 논문은 end-to-end LLM 에이전트 기반 메서드 수준 자동 리팩터링 솔루션 MANTRA(Multi-AgeNT Code RefActoring)를 제안한다. 주어진 메서드와 리팩터링 유형에 대해 완전 컴파일·가독·테스트 통과 코드를 생성한다. MANTRA는 세 핵심 구성요소를 갖는다: (1) few-shot 예시를 위한 검색 가능 데이터베이스를 구축하는 Context-Aware Retrieval-Augmented Refactored Code Generation, (2) Developer Agent와 Reviewer Agent로 실제 리팩터링 과정을 모사하는 Multi-Agent Refactored Code Generation, (3) verbal reinforcement learning 프레임워크로 컴파일·테스트 실패 원인을 반복 식별·수정하는 Self-Repair Using Verbal Reinforcement Learning. 10개 Java 프로젝트로 평가하며 PurityChecker로 703개 순수 리팩터링을 수집해 6개 최빈 리팩터링 활동을 다뤘고, RawGPT·EM-Assist·인간 작성 코드와 비교했다. 절제 연구에서 어느 구성요소를 빼도 성능이 크게 하락(40.7%~61.9%)했으며 Reviewer Agent 기여가 가장 컸다.
