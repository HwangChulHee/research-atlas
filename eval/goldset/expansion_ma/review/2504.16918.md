## 초록+서론 한글 번역
최적화는 과학·응용에서 핵심이나, 자연어로 기술된 문제를 수학적 형태로 정식화하고 적합한 solver를 고르는 데는 상당한 도메인 전문성이 필요하다. 우리는 LLM 기반 AI 에이전트로 자연어 최적화 문제를 푸는 프레임워크 OptimAI를 소개하며 최신 방법을 능가한다. 핵심 역할: (1) 자연어 문제를 수식으로 옮기는 formulator, (2) 실행 전 고수준 해법 전략을 세우는 planner, (3) 환경과 상호작용하며 반성해 다음 행동을 정제하는 coder와 code critic. 절제 실험은 모든 역할이 필수임을 확인한다(planner·code critic 제거 시 생산성 5.8배·3.1배 하락). UCB 기반 디버그 스케줄링으로 대안 계획을 동적 전환해 추가 3.3배 생산성 향상을 얻는다. 다양한 모델 조합이 성능 향상을 준다. NLP4LP 88.1%, Optibench 82.3% 정확도로 이전 최고 대비 오류율을 각각 58%·52% 줄였다.

서론: 최적화는 의사결정·자원배분·시스템설계의 핵심 틀이며 현대 ML은 대규모 최적화(손실 최소화, 하이퍼파라미터 튜닝, 정책학습) 위에 서 있다. 그러나 실세계 목표가 수학적으로 표현되는 일은 드물어 비전문가에게 최적화는 접근이 어렵다("배송시간 최소화"를 형식 모델로 옮기려면 정식화·solver 선택 전문성이 필요). 자연어처리·기호추론의 진전은 직관적 문제기술을 해석해 유효한 최적화 정식화를 구성하는 자동 시스템의 길을 연다. LLM은 자연어로 복잡 과제와 상호작용하는 강력한 도구이며 수학·코딩·논리 추론 능력을 보인다. 우리는 실세계 문제를 형식 모델로 옮기는 장벽을 낮추고 LLM의 최적화 추론 한계를 탐구하려 OptimAI를 도입한다. 각 단계를 전문 에이전트가 맡는 네 단계로 구성되며, plan-before-code 전략(코드 생성 전 다수 계획 생성), UCB 기반 디버그 스케줄링(관측 피드백에 따라 대안 계획 적응 선택), 그리고 역할별로 가장 적합한 서로 다른 LLM을 쓰는 멀티에이전트 협업을 자연스럽게 지원한다. 서로 다른 LLM 조합이 시너지를 낸다. 표준 수리계획을 넘어 NP-hard 조합최적화도 다뤄 일반성을 보인다.
