# 2309.07870 — Agents: An Open-source Framework for Autonomous Language Agents

**한 줄 핵심**: 계획·메모리·툴 사용·멀티에이전트 통신·기호적 제어(SOP)를 지원하는 오픈소스 언어 에이전트 프레임워크로, 비전문가도 최소 코딩으로 (멀티)에이전트를 구축·튜닝·배포하게 함.

**keep/drop**: keep — 멀티에이전트 통신 및 controller("moderator") 에이전트를 통한 dynamic scheduling(오케스트레이션)을 핵심 기능으로 포함한 프레임워크. (다만 일반 에이전트 프레임워크로서 멀티에이전트가 여러 기능 중 하나여서 경계에 있음.)

**builds_on 초안**: [] (근거: AutoGPT/BabyAGI는 "이들 데모는 커스터마이즈·튜닝이 어렵다"는 비판 대상일 뿐 이 프레임워크의 멀티에이전트 방법이 그 위에서 확장된 것이 아니어서 제외. "Following [Patil et al., 2023]"(Gorilla)로 툴 사용을 따랐다 하나 본문에 시스템명이 표면화되지 않았고 핵심 MA 방법의 계보가 아니라 제외. SOP/dynamic scheduling은 self-defined. VectorDB는 부품, RAG는 범주어라 제외.)

**경계 플래그**: (1) AutoGPT, BabyAGI를 named 선행 시스템으로 언급 — 한계 지적(D2 후보)이지만 방법 계보라기보다 포지셔닝 대비여서 제외했으나 계보로 볼지 애매하여 flag. (2) 이 논문 자체가 프레임워크(라이브러리)라 keep/drop 및 계보 판정 모두 경계적임.

## 초록+서론 한글 번역
LLM의 최근 발전으로 연구자·개발자는 자연어 인터페이스로 다양한 과제를 자동 해결하고 환경·인간·다른 에이전트와 상호작용하는 자율 언어 에이전트를 만들 수 있게 됐다. 우리는 언어 에이전트를 AGI로 향하는 유망한 방향으로 보고, 이 발전을 비전문가 대중에게 열기 위한 오픈소스 라이브러리 AGENTS를 공개한다. AGENTS는 계획, 메모리, 툴 사용, 멀티에이전트 통신, 세밀한 기호적 제어 같은 중요한 기능을 지원하도록 정교하게 설계됐고, 비전문가도 코딩 없이 최신 자율 언어 에이전트를 구축·커스터마이즈·테스트·튜닝·배포할 수 있어 사용자 친화적이며, 모듈형 설계로 연구자에게도 확장 친화적이다.

ChatGPT 같은 LLM은 인지·추론·계획·행동으로 복잡한 과제를 자동 해결하는 자율 에이전트 구축을 가능케 한다. AutoGPT, BabyAGI 같은 최근 데모가 언어 에이전트의 잠재력을 보였으나, 대부분 커스터마이즈·튜닝·배포가 친화적이지 않다. 이는 이들이 대개 개념 증명(proof-of-concept)에 그치고, 시간에 걸쳐 에이전트를 구축·커스터마이즈할 큰 프레임워크가 아니기 때문이다. 또한 대부분의 오픈소스 저장소는 과제 분해, 장·단기 메모리, 웹 내비게이션, 툴 사용, 멀티에이전트 통신 같은 핵심 능력의 일부만 다룬다. 게다가 기존 언어 에이전트 프레임워크는 대개 짧은 과제 설명에만 의존하고 계획·행동을 전적으로 LLM 능력에 맡겨 실행마다 큰 무작위성·불일치를 낳는다.

이에 우리는 LLM 기반 언어 에이전트를 위한 오픈소스 라이브러리·프레임워크 AGENTS를 공개한다. 철학은 비전문가도 커스터마이즈·튜닝·배포를 최대한 쉽게 하면서 개발자·연구자에게 확장 친화적으로 남는 것이다. 주요 기능: (a) 장·단기 메모리 — VectorDB·의미 검색으로 장기 메모리 저장·검색, 스크래치패드로 단기 작업 메모리 갱신; (b) 툴 사용 & 웹 내비게이션 — [Patil et al., 2023]을 따라 흔한 외부 API를 지원하고 웹 검색·내비게이션을 전용 API로 정의; (c) 멀티에이전트 통신 — 게임, 사회 실험, 소프트웨어 개발 등에 유용하며, 하드코딩 규칙 대신 controller 에이전트가 "moderator"로서 역할·이력을 고려해 다음에 행동할 에이전트를 정하는 "dynamic scheduling" 신기능 제공; (d) 인간-에이전트 상호작용 — 단일·멀티에이전트 모두에서 인간이 에이전트와 통신·상호작용; (e) 제어가능성 — 기호적 계획(SOP, 표준운영절차)으로 제어 가능한 에이전트를 구축. SOP는 여러 상태와 전이 규칙의 그래프로, LLM이 생성하고 사용자가 편집할 수 있으며 세밀한 행동 제어를 제공한다. 또한 짧은 과제 설명이 주어지면 retrieval-augmented generation으로 config 파일을 생성하는 "메타 에이전트" 자동 SOP 생성 파이프라인을 제안한다.
