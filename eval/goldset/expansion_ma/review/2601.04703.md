# 2601.04703 — Beyond Monolithic Architectures: A Multi-Agent Search and Knowledge Optimization Framework for Agentic Search (M-ASK)

**한 줄 핵심**: 단일(monolithic) agentic search 에이전트가 겪는 무제한 출력·희소 보상·검색잡음 문제를, 검색행동 에이전트와 지식관리 에이전트로 역할 분리하고 턴 단위 dense reward로 공동 최적화하는 멀티에이전트 검색 프레임워크.

**keep/drop**: keep — 역할 분리된 에이전트들의 협업 오케스트레이션(검색↔지식관리)이 본질인 멀티에이전트 방법 논문.

**builds_on 초안**: [Search-R1] (근거: 본문이 "Represented by Search-r1 ... recent advancements integrate reasoning directly into LLM-based multi-round search"라 하고, monolithic 아키텍처(Search-R1 인용)의 한계를 지적하며 그것을 역할분리로 개선 → D2 "한계 위에서 고침" 계보. RL/GRPO 등 옵티마이저는 D1 제외, turn-level dense reward는 self 기법.)

**경계 플래그**: Agentic Search(Shi et al.) — 이 논문이 속한 상위 패러다임/범주어라 계보 표면화 보류(D4). Search-R1은 구체 named 시스템이라 포함.

## 초록+서론 한글 번역
Agentic search는 LLM이 추론과 도구사용을 교차하며 복잡한 정보탐색을 하게 하는 유망한 패러다임으로 떠올랐다. 그러나 기존 시스템은 monolithic 에이전트에 의존해 구조적 병목을 겪는다: 궤적을 부풀리는 무제한 추론 출력, 신용할당을 어렵게 하는 희소한 결과단위 보상, 학습을 불안정하게 하는 확률적 검색잡음. 이를 위해 M-ASK(Multi-Agent Search and Knowledge)를 제안한다. agentic search를 두 상보적 역할로 명시 분리한다: 검색행동을 계획·실행하는 Search Behavior Agents와, 압축된 내부 맥락을 집계·필터·유지하는 Knowledge Management Agents. 이 분해로 각 에이전트가 잘 정의된 하위작업에 집중해 검색과 맥락구성 간 간섭을 줄인다. 나아가 안정적 조율을 위해 turn-level 보상으로 검색 결정과 지식 갱신 모두에 세밀한 감독을 준다. 멀티홉 QA 실험에서 M-ASK는 강한 baseline을 능가해 정확도뿐 아니라 훨씬 안정적인 학습 동역학을 보인다.

서론: LLM의 급속 발전은 수동 키워드 매칭에서 Agentic Search로의 패러다임 전환을 이끌었다. Agentic search 시스템은 반복 계획·외부 도구 질의·정보 종합을 수행하는 자율 의사결정자다. Search-R1로 대표되는 최근 진전은 추론을 LLM 기반 다중 라운드 검색 워크플로에 직접 통합해, 단일 응답 내에서 다단계 검색을 end-to-end 최적화하여 복잡 QA 성능을 크게 높였다. 그러나 이런 동적 검색 환경에서 견고한 에이전트를 훈련하는 데는 큰 도전이 있다. 지배적 접근은 단일·연속 응답 내에서 다중 라운드 검색을 실행하는 monolithic 아키텍처로, LLM이 매 반복마다 궤적 계획과 정보 처리의 부담을 동시에 진다. 이 설계는 세 장애에 구조적으로 취약하다: (i) 무제한 출력 길이(정보밀도 없이 장황한 추론), (ii) 희소 보상(완료까지 지연된 피드백으로 단계별 신용할당 저해), (iii) 검색잡음(검색엔진이 잡음·무관 데이터 유입). 이들은 상호작용해 장기 신용할당 문제로 학습을 불안정하게 한다. 이를 극복하려 M-ASK는 검색의 의사결정과 정보통합 부담을 근본적으로 분리한다. 단일 에이전트 대신 두 전문 역할을 조율한다: (1) 궤적 계획·검색엔진 상호작용·답 생성에 집중하는 Search Behavior Agents(Planning·Search·Answer), (2) 잡음 관측을 잘라내고 간결한 내부 지식상태를 유지·갱신해 맥락 길이를 제약하는 Knowledge Management Agents(Summary·Update). 희소 피드백 대신 turn-specific dense reward로 모든 에이전트를 즉각적·턴 인식 감독으로 공동 최적화한다.
