# 2312.13010 — AgentCoder: Multi-Agent-based Code Generation with Iterative Testing and Optimisation

**한 줄 핵심**: 프로그래머·테스트 설계자·테스트 실행자 3개 에이전트가 반복 피드백 루프로 협업하여, 코드와 독립적 테스트를 생성·검증하며 코드 생성 성능·토큰 효율을 함께 높이는 다중 에이전트 코드 생성 프레임워크.

## 초록+서론 한글 번역
트랜스포머 기반 LLM 발전으로 NLP, 특히 코드 생성이 크게 향상되어 개발자의 소프트웨어 작성 효율을 높였다. 그러나 코드 스니펫 생성과 효과적 테스트 케이스의 균형에는 여전히 난제가 있다. 이를 해결하기 위해 본 논문은 프로그래머 에이전트·테스트 실행자 에이전트에 더해 전문화된 테스트 설계자 에이전트를 포함한 다중 에이전트 프레임워크인 AgentCoder를 제안한다. 코딩 과정에서 테스트 설계자 에이전트가 생성 코드에 대한 효과적 테스트 케이스를 만들고, 테스트 실행자 에이전트가 코드를 테스트와 함께 실행해 프로그래머 에이전트에 피드백을 써주어 코드를 개선하게 한다. 이 협업 시스템은 더 적은 비용으로 코드 생성 효율을 높여 단일 에이전트 모델과 기존 다중 에이전트 전략을 모두 능가한다(14개 LLM, 16개 베이스라인 실험). 예컨대 AgentCoder(GPT-4)는 HumanEval·MBPP에서 각각 96.3%·91.8% pass@1을, 토큰 오버헤드 56.9K·66.3K로 달성한다(SOTA는 90.2%·78.9%, 138.2K·206.5K).

최근 LLM은 다양한 in-context learning으로 개선되어 왔으며, 중요한 최적화 경로 중 하나는 같은 대화 내 단일 에이전트 self-refinement다. 예컨대 Zhang et al.은 Self-Edit를 제안했는데, 개발자가 수작업으로 쓴 테스트에 대해 생성 코드를 실행하고 실패 테스트의 오류 메시지로 코드를 개선하도록 LLM에 프롬프트한다. Huang et al.은 CodeCoT를 도입해 LLM으로 코드와 테스트를 모두 생성하여 개발자 제공 테스트 의존을 피했다. 최근 MetaGPT, ChatDev, AgentVerse 등 여러 연구가 다중 에이전트 협업으로 LLM 기반 코드 생성 효과를 높이려 했으며, 각 에이전트가 코드 생성이나 과제 계획 같은 고유 업무를 맡는다. 이 프레임워크들은 작업 분산·성능 최적화로 단일 에이전트의 한계를 극복하려 하나 두 가지 한계가 있다: 1) 효과적 피드백 메커니즘 부재(MetaGPT의 HumanEval 생성 테스트 정확도는 80%에 불과), 2) 과도한 에이전트 수(MetaGPT 5, ChatDev 7)로 통신·조율에 많은 토큰 자원 소모. 이를 해결하기 위해 효과적 테스트 생성과 적은 토큰 오버헤드를 갖는 다중 에이전트 코드 생성 프레임워크 AgentCoder를 제안한다. AgentCoder는 프로그래머·테스트 설계자·테스트 실행자 세 단순 에이전트만을 갖는다. 프로그래머 에이전트는 요구사항으로 코드를 생성하고, 테스트 설계자 에이전트는 요구사항 기반으로 코드와 독립적으로 정확·다양·포괄적 테스트를 설계하며, 테스트 실행자 에이전트는 설계 테스트를 생성 코드에 실행해 결과를 프로그래머에 피드백한다. 오류가 있으면 프로그래머가 버그를 수정하고, 모든 테스트 통과 또는 반복 예산 소진까지 반복한다. AgentCoder는 CodeCoT·MetaGPT의 테스트 생성 대비 세 특징을 갖는다: 첫째, 전체 코드를 보지 않고 테스트를 생성해 편향·다양성 저하를 피함; 둘째, 소스 코드 생성과 테스트 생성을 의도적으로 분리; 셋째, 테스트 설계자가 기본·경계·대규모 테스트를 생성해 높은 정확도·커버리지를 얻는다.
