## 초록+서론 한글 번역
언어 에이전트는 특히 LLM 위에 구축될 때 다양하고 복잡한 과제에 자연어를 활용할 잠재력을 보인다. 현재의 언어 에이전트 프레임워크는 개념증명 구축에 초점을 맞추면서 비전문가 사용자 접근과 애플리케이션 수준 설계는 소홀히 한다. 우리는 일상 속에서 언어 에이전트를 사용·호스팅하는 오픈 플랫폼 OpenAgents를 제시한다. OpenAgents는 세 에이전트를 포함한다: (1) Python/SQL·데이터 툴로 데이터 분석을 하는 Data Agent, (2) 200+ 일상 API 툴을 갖춘 Plugins Agent, (3) 자율 웹 브라우징을 위한 Web Agent. 일반 사용자는 신속 응답에 최적화된 웹 UI로 에이전트 기능과 상호작용하고, 개발자·연구자는 로컬에 매끄럽게 배포할 수 있어 새로운 언어 에이전트 제작과 실세계 평가의 토대를 제공한다.

지능 에이전트는 환경을 감지·결정·행동하는 자율 문제 해결자로 개념화된다. LLM의 등장으로 학계·산업·오픈소스 커뮤니티가 이 개념을 활용해 언어 에이전트를 만들었다. 한편 현재의 에이전트 프레임워크(LangChain, AutoGPT, BabyAGI 등)는 개발자용 개념증명 구현과 콘솔 인터페이스를 제공해 프로그래밍에 익숙지 않은 더 넓은 대중의 접근을 제한한다. 현재 에이전트 벤치마크는 코딩·툴 사용·웹 브라우징 등 특정 환경 내 결정론적 평가로 구성되나, 일반적 에이전트 사용은 더 열린 환경과 실제 사용자의 특수한 요구·자료와 연결된다.

OpenAI는 Advanced Data Analysis(구 Code Interpreter), Plugins, Browse with Bing 같은 잘 설계된 제품을 배포했으나, 모델·비즈니스 로직 코드는 사업적 이유로 공개되지 않아 사용자의 자유 접근과 개발자·연구자의 탐구·평가·개선을 막는다. 이를 인식해 OpenAgents는 에이전트 접근을 민주화하는 오픈소스 플랫폼으로서, 현재 Data Agent, Plugins Agent(200+ 툴), Web Agent를 아우른다. 일반 사용자는 코딩 없이 온라인 웹 UI로 에이전트 능력을 탐색하고, 개발자는 로컬에 배포하며, 연구자는 새 언어 에이전트를 구축한다. 나아가 실제 사용자가 실제 요구를 채우려 에이전트와 상호작용하고 그 인간-에이전트 궤적·피드백이 기록되는 현실적·총체적 인간-인더-루프 평가 플랫폼을 지향한다.

구축 과정에서 우리는 LLM 프롬프팅으로 애플리케이션 요구를 효과적으로 명세하는 것의 중요성(백엔드 로직·출력 미학·적대적 입력 방어를 위한 지시 작성), 토큰 한계·컨텍스트 처리의 어려움, 스트리밍 같은 실시간 상호작용 처리의 필요성, 그리고 현재 연구가 이상적 성능 지표에 치우쳐 시스템 응답성-정확성 트레이드오프 같은 실세계 고려를 간과하는 문제를 강조한다.
