# 2402.05120 — More Agents Is All You Need (Agent Forest)
**한 줄 핵심**: 동일 쿼리를 다수 에이전트에 반복 입력해 출력을 샘플링하고 다수결 투표로 집계하는 단순 방법(Agent Forest)으로, 에이전트 수 증가에 따른 LLM 성능 스케일링 현상을 규명한다.
**keep/drop**: keep — 다수 LLM 에이전트를 인스턴스화하는 방법 논문(orchestration 섹션). 단, 에이전트 간 상호작용·통신이 없는 샘플링-투표 앙상블이라 "협업/오케스트레이션 본질성"이 약해 경계 플래그.
**builds_on 초안**: [CoT-SC] (근거: 서론 "The procedure is inspired by that of the CoT-SC"—샘플-투표 절차를 CoT-SC(자기일관성) 절차에서 딛어 확장·단순화. D2 통과. Random Forest는 이름 오마주(tribute)일 뿐이라 D3로 제외. LLM-Debate(Du et al.)·CoT는 대조/플러그인 대상이지 확장 계보 아님.)
**경계 플래그**: (1) keep/drop 경계 — 에이전트들이 서로 소통하지 않고 독립 샘플링 후 투표만 하므로 진정한 멀티에이전트 협업/오케스트레이션인지 애매(사실상 대규모 앙상블/자기일관성). (2) "Random Forest" 오마주 이름은 계보에서 제외.

## 초록+서론 한글 번역
저자들은 단순한 샘플링-투표(sampling-and-voting) 방법만으로 LLM 성능이 인스턴스화된 에이전트 수에 따라 스케일링됨을 발견한다. Agent Forest라 명명한 이 방법은 LLM을 강화하는 기존 복잡한 방법들과 직교(orthogonal)하며, 강화 정도는 과제 난이도와 상관된다. 광범위한 LLM 벤치마크 실험으로 이 현상의 존재와 발생 조건을 검증한다.

서론: LLM은 다양한 능력에도 복잡한 과제에서 정확한 답을 내지 못한다. 성능 향상을 위해 최근 연구는 앙상블 방법과 다수 LLM 에이전트 협업 프레임워크에 주목한다. 예로 LLM-Debate[Du et al. 2023]는 다수 LLM 에이전트가 산술 과제의 최종 답을 "토론"하게 해 단일 에이전트 대비 성능을 개선하고, CoT-SC[Wang et al. 2023b]는 다수 사고 사슬을 생성해 가장 자기일관적인 것을 최종 답으로 골라 단일 CoT보다 추론 성능을 높인다. 이런 작업들의 데이터에서 다수 에이전트를 함께 두는 효과가 특정 문제에서 성능 향상으로 이어질 수 있음을 관찰한다(예: LLM-Debate 표10에서 토론 에이전트 수가 1→7로 늘 때 정확도 증가). 그러나 "raw" 에이전트의 스케일링 속성은 이들의 초점이 아니어서 시나리오·실험이 제한적이었다. 따라서 "이 현상이 일반적으로 존재하는가?"라는 질문이 생긴다. 이에 저자들은 LLM 에이전트 스케일링 속성에 대한 최초의 포괄적 연구를 수행한다. 방법은 두 단계로, 과제 쿼리를 단일 LLM(또는 다수 LLM 협업 프레임워크)에 반복 입력해 다수 출력을 생성하고, 다수결 투표로 최종 결과를 정한다. 이 절차는 CoT-SC에서 착안했으나 복잡한 CoT 경로 설계에 의존하지 않으며, CoT 기반 방법을 강화하는 플러그인으로도 쓸 수 있다. 방법 이름 Agent Forest는 고전적 Random Forest[Breiman 2001]에 대한 오마주다. 다양한 크기 LLM과 데이터셋 실험 결과, 에이전트 수(앙상블 크기) 증가로 성능이 전반적으로 개선되며, 소형 LLM의 무차별 앙상블이 대형 LLM과 대등하거나 우수한 성능을 낼 수 있다. 난이도가 높거나 약한 모델일수록 개선 폭이 크다.
