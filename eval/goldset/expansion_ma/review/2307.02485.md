# 2307.02485 — Building Cooperative Embodied Agents Modularly with Large Language Models (CoELA)

**한 줄 핵심**: 지각·기억·통신·계획·실행 5개 모듈로 이루어진 인지 구조 기반 프레임워크 CoELA로, 탈중앙·비용 있는 통신 환경에서 다중 임베디드 에이전트가 자연어로 협력하는 방법.

**keep/drop**: keep — 탈중앙 다중 에이전트 협력·통신이 방법의 본질(두 에이전트가 자연어로 분업·협업).

**builds_on 초안**: [] (근거: 방법이 딛은 명명된 선행 기법이 본문에 없음. "Inspired by prior work in cognitive architectures (Laird, 2019)"는 named 시스템이 아닌 범주어(cognitive architectures)이며, LoRA(Hu et al. 2021)는 파인튜닝 도구로 제외. GPT-4·LLAMA-2는 백본/베이스라인. CoELA·CoLLAMA는 self 정의.)

## 초록+서론 한글 번역
본 연구는 탈중앙 제어, 원시 감각 관찰, 비용이 드는 통신, 다목적 과제를 특징으로 하는 도전적 다중 에이전트 협력 문제를 다룬다. 기존 연구가 비용 없는 통신 채널을 전제하거나 공유 관찰을 갖는 중앙 컨트롤러에 의존한 반면, 본 연구는 LLM의 상식 지식·추론 능력·언어 이해·텍스트 생성 능력을 활용해 지각·기억·실행과 통합되는 인지 영감 모듈형 프레임워크에 매끄럽게 결합한다. 이렇게 계획·통신·협력하여 장기 과제를 효율적으로 수행하는 협력적 임베디드 언어 에이전트 CoELA를 구축한다. C-WAH와 TDW-MAT 실험에서 GPT-4로 구동되는 CoELA가 강력한 계획 기반 방법을 능가하고 창발적 효율 통신을 보였다. LLAMA-2 같은 오픈 LM은 아직 부진하나, 에이전트로 수집한 데이터로 CoLLAMA를 파인튜닝해 유망한 성능을 보였다. 사용자 연구에서 자연어로 소통하는 CoELA가 더 큰 신뢰를 얻고 인간과 더 효과적으로 협력함을 발견했다.

인간은 복잡한 과제를 풀 때 타인과 협력·소통에 능하다. 일상에서 인간을 돕는 임베디드 에이전트를 만드는 것은 가치 있으나, 지각·부분 관찰·장기 계획·자연어 통신의 복잡성 때문에 도전적이다. LLM은 여러 영역에서 뛰어난 능력을 보였다. 최근 연구는 LLM이 zero-shot 프롬프팅이나 few-shot 프롬프팅으로 단일 에이전트 임베디드 과제를 구동할 수 있음을 보였다. 그러나 비용 있는 통신의 탈중앙 환경에서 다른 에이전트·인간과 협력하는 임베디드 에이전트를 만드는 것은 여전히 도전적이고 거의 탐구되지 않았으며, 강한 협력 계획·효율 통신 능력이 필요하다. LLM이 분산 임베디드 다중 에이전트 협력에 필요한 능력을 갖는지는 불분명하다. 본 논문은 두 탈중앙 임베디드 에이전트가 복잡한 부분 관찰 하에서 다목적 가사 과제를 효율적으로 협력 수행해야 하는 환경에 초점을 둔다. 통신에 시간이 들어 자유롭게 계속 대화할 수 없으며, 성공하려면 에이전트는 (i) 관찰에서 유용 정보 추출, (ii) 세계·과제·타인에 대한 기억 유지, (iii) 효율을 위한 소통 내용·시점 결정, (iv) 공동 목표를 위한 협력 계획을 해야 한다. 인지 구조(Laird, 2019) 선행 연구에서 영감을 받아, LLM의 풍부한 세계 지식·추론·자연어 이해·생성 능력을 활용하는 신규 모듈형 프레임워크인 CoELA를 제시한다. 프레임워크는 관찰을 지각해 유용 정보를 추출하는 Perception Module, 인간의 장기 기억을 모사해 물리 환경과 타 에이전트에 대한 이해를 유지하는 Memory Module, 무엇을 소통할지 결정하는 Communication Module, 소통 시점을 포함한 고수준 계획을 결정하는 Planning Module, 기억에 저장된 절차로 원시 행동을 생성해 계획을 실행하는 Execution Module의 5개 모듈로 구성된다. TDW-MAT·C-WAH 두 환경에서 평가하며, GPT-4 구동 CoELA가 강한 계획 기반 베이스라인 대비 40% 이상의 효율 향상을 달성하고 창발적 효율 통신을 보였다. 오픈 LM은 부진하나 LoRA로 CoLLAMA를 소량 데이터로 학습해 유망한 성능을 얻었다.
