## 초록+서론 한글 번역
소프트웨어 개발은 다양한 기술을 가진 여러 구성원의 협력이 필요한 복잡한 작업이다. 많은 연구가 딥러닝으로 워터폴 모델의 특정 단계(설계·코딩·테스트)를 개선했으나, 각 단계의 딥러닝 모델은 고유한 설계를 요구해 단계 간 기술적 불일치가 생기고 개발 과정이 파편화·비효율화된다. 본 논문은 ChatDev를 제안한다. LLM으로 구동되는 전문 에이전트들이 무엇을 소통할지(chat chain)와 어떻게 소통할지(communicative dehallucination)를 안내받아, 통합된 언어 기반 소통으로 설계·코딩·테스트 단계에 능동적으로 기여하고 다중턴 대화에서 해법을 도출한다. 자연어 소통은 시스템 설계에 유리하고, 프로그래밍 언어 소통은 디버깅에 유용함을 발견했다. 이 패러다임은 언어적 소통이 멀티에이전트 협업을 촉진함을, 즉 언어가 LLM 에이전트 간 자율적 문제해결의 통합 다리가 됨을 보인다.

서론: LLM은 방대한 지식 통합 능력과 지정된 역할 내 롤플레잉 능력으로 큰 변화를 이끌었고, 자율 에이전트는 문맥 인식 메모리·다단계 계획·전략적 도구 사용 등으로 LLM 능력을 확장해 왔다. 소프트웨어 개발은 아키텍트·프로그래머·테스터 등 다양한 역할의 협력을 요하며, 자연어로 요구사항을 이해·분석하고 프로그래밍 언어로 개발·디버깅한다. 기존 딥러닝 기반 단계별 방법은 각기 고유 설계가 필요해 서로 고립되어 있었다. 저자들은 언어를 통합 다리로 삼아 전문 역할의 다중 LLM 에이전트가 언어 기반 소통으로 협력 개발하도록 목표한다. 다만 LLM 환각으로 인해 불완전·실행불가·부정확한 코드가 생성되는 coding hallucination 문제가 있어 추가 수작업이 필요해진다. 이에 ChatDev는 chat chain으로 각 단계를 하위작업으로 분해해 에이전트의 다중턴 소통으로 해법을 제안·개발하게 하고, communicative dehallucination 메커니즘으로 에이전트가 직접 응답 전에 더 구체적인 세부를 능동적으로 요청하게 하여 코딩 환각을 줄인다. 구축한 데이터셋 실험 결과 ChatDev는 완결성·실행성·요구사항 일치도 면에서 소프트웨어 품질을 크게 개선했다.
