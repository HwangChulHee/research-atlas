# 2310.20151 — Multi-Agent Consensus Seeking via Large Language Models

**한 줄 핵심**: LLM 기반 다중 에이전트가 수치 상태를 협상해 합의값에 도달하는 '합의 탐색(consensus seeking)' 과제를 정의하고, 에이전트 수·성격·네트워크 토폴로지가 협상에 미치는 영향을 분석하며 다중 로봇 집결 과제에 적용한다.

## 초록+서론 한글 번역
LLM으로 구동되는 다중 에이전트 시스템은 복잡 과제를 협력적으로 푸는 유망한 능력을 보였다. 본 연구는 다중 에이전트 협업의 근본 문제인 '합의 탐색'을 다룬다. 여러 에이전트가 협력할 때, 이들이 에이전트 간 협상을 통해 어떻게 합의에 도달하는지에 관심을 둔다. 이를 위해 각 에이전트의 상태가 수치값이고 서로 협상해 합의값에 이르는 과제를 연구한다. 어떤 전략을 쓸지 명시적으로 지시받지 않으면 LLM 구동 에이전트는 주로 평균 전략(average strategy)을 사용함을 밝힌다. 또한 에이전트 수, 성격, 네트워크 토폴로지가 협상 과정에 미치는 영향을 분석한다. 이 발견은 더 복잡한 과제를 위한 LLM 다중 에이전트 시스템의 행동 이해에 토대가 될 수 있다. 나아가 LLM 구동 합의 탐색을 다중 로봇 집결 과제에 적용해, 단순 언어 명령으로 제로샷 자율 계획이 가능함을 보인다.

서론: 최근 LLM 다중 에이전트 시스템이 급격히 주목받고 있으며, 다중 에이전트 협업으로 LLM의 문제 해결력이 크게 향상된다고 보고된다. MetaGPT, CAMEL, ChatDev는 복잡 과제를 단순 하위과제로 분해해 서로 다른 에이전트가 처리하게 하여, 어느 정도 환각을 줄이고 복잡 과제 해결력을 높인다. 본 연구는 근본 문제인 합의 탐색을 다룬다. 여러 LLM이 같은 과제를 풀 때 초기 해가 다르더라도 지속적 협상으로 결국 같은 해에 도달할 수 있는데, 이것이 본질적으로 합의 탐색 과정이다. 합의 탐색은 동물 집단·인간 사회 같은 집단 의사결정과 다중 로봇 시스템, 연합학습의 핵심 연구 문제다. LLM을 통한 합의 탐색은 아직 잘 이해되지 않았다. 여러 LLM이 결국 합의에 도달하는지, 도달한다면 얼마나 걸리고 무엇이 결과에 영향을 주는지, 못한다면 어떤 요인 때문인지 등의 질문이 중요하다. 문제 설정은 각 에이전트가 초기 수치 상태에서 시작해 타 에이전트 상태를 관측하며 자신의 상태를 조정해 동일 최종 상태에 이르는 것이다. 주요 발견: (1) 미지시 시 평균 전략을 자주 사용, (2) 완고한(stubborn) 성격 에이전트가 최종 합의값을 지배해 리더-팔로워 구조 형성, (3) 완전연결 토폴로지는 빠른 수렴, 방향그래프는 계층구조 형성, 성격·토폴로지 상호작용으로 미합의(군집화)도 발생, (4) 에이전트 수 증가 시 최종 합의값 분산 감소로 무작위성/환각 완화. 마지막으로 이 프레임워크를 다중 로봇 집결(유클리드 공간의 합의 탐색)에 협력적 계획자로 적용한다.
