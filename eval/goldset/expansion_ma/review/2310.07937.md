# 2310.07937 — Co-NavGPT: Multi-Robot Cooperative Visual Semantic Navigation Using Vision Language Models

**한 줄 핵심**: Vision Language Model을 전역 플래너로 삼아, 여러 로봇의 부분 지도를 통합 전역 지도로 합치고 각 로봇에 frontier를 배정해 협력적으로 목표 물체를 탐색하는 다중 로봇 시각 의미 내비게이션 프레임워크.

**keep/drop**: keep — 다중 로봇의 협력적 탐색·frontier 배정 조율이 방법의 본질.

**builds_on 초안**: [] (근거: 방법이 딛은 명명된 선행 기법이 본문에 없음. frontier 기반 탐색 개념을 쓰나 특정 named frontier 기법을 지목하지 않음. 기존 접근을 "end-to-end frameworks"와 "modular pipelines" 범주로만 서술. VLM은 백본. Co-NavGPT는 self 정의.)

- VLM(Vision Language Model)은 전역 플래너 역할의 백본 모델(제외).

## 초록+서론 한글 번역
시각 목표 내비게이션은 미지 환경에서 작동하는 자율 로봇, 특히 인간-로봇 상호작용 시나리오의 핵심 능력이다. 고전·학습 기반 방법이 가능성을 보였으나 대부분 상식 추론이 부족하고 단일 로봇 설정을 전제해, 복잡 환경에서 효율·강건성이 떨어진다. 이를 해결하기 위해 Vision Language Model(VLM)을 전역 플래너로 통합해 상식 기반 다중 로봇 시각 목표 내비게이션을 가능케 하는 신규 프레임워크 Co-NavGPT를 제안한다. Co-NavGPT는 다양한 시점을 가진 여러 로봇의 부분 지도를 하나의 통합 전역 지도로 합치고, 로봇 상태와 frontier 영역을 인코딩한다. VLM은 이 정보를 사용해 각 로봇에 frontier를 배정하여 협력적·효율적 탐색을 촉진한다. Habitat-Matterport 3D(HM3D) 실험에서 Co-NavGPT는 성공률·내비게이션 효율에서 기존 베이스라인을 능가했으며, 과제 특화 학습 없이 이를 달성했다. 절제 연구는 VLM의 의미 사전지식의 중요성을 확인했고, 사족 로봇으로 실세계 시나리오에서도 검증했다.

인간은 환경 구조에 대한 상식과 협력 전략을 활용해 복잡한 환경을 효율적으로 탐색한다. 자율 로봇도 유사한 추론 능력이 필요하다. 예컨대 두 로봇에게 "내 휴대폰을 가져다줘"라고 지시하면, 두 로봇이 협력해 대상 물체를 찾는 것이 첫 핵심 단계다. 물체 목표 내비게이션·다중 로봇 탐색에 상당한 진전이 있었으나, 시각 입력으로부터 로봇들이 협력해 목표 물체를 식별·탐색하는 것은 의미적 복잡성과 환경 난해함 때문에 여전히 도전적이다. 본 논문은 여러 로봇이 협력해 미지 환경에서 특정 물체를 효율적으로 찾는 다중 로봇 시각 목표 내비게이션 과제를 다룬다. 기존 접근은 크게 end-to-end 프레임워크와 modular pipeline으로 나뉘며, 공간·의미 특징을 지도·강화 학습으로 통합해 성능을 높인다. 최근 VLM이 내비게이션 파이프라인에 도입되어 의미 추론·물체 그라운딩 강점을 활용하나, 대다수 기존 방법은 단일 로봇 설정용이다. 크거나 복잡한 환경에서 단일 에이전트 내비게이션은 광대한 미지 영역 탐색으로 효율이 낮고, 한 번의 잘못된 결정·장애물로 실패에 취약하다. 학습 기반 접근은 다양한 환경 일반화를 위해 대량 데이터·연산이 필요하며 다중 로봇에서 더 심해진다. VLM의 등장으로 임베디드 과제의 zero/few-shot 계획 기회가 열렸고, VLM은 내재된 세계 지식으로 고수준 플래너로서 가능성을 보였다. 본 논문은 다중 로봇 시각 의미 내비게이션 과제를 다루며, VLM을 활용해 다중 로봇 협력의 효율적 탐색·검색 정책을 생성하는 신규 프레임워크 Co-NavGPT를 제안한다.
