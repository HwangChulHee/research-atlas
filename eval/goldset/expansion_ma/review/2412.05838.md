## 초록+서론 한글 번역
검색 증강 생성(RAG)은 외부의 도메인 특화 데이터를 생성 과정에 통합해 LLM을 강화한다. LLM은 강력하지만 정적·사전학습 데이터에 의존해 동적/사설 데이터 통합이 제한된다. 전통적 RAG 시스템은 질의 생성·데이터 검색·응답 합성을 하나의 단일 에이전트 아키텍처로 처리하는데, 관계형 DB·문서 저장소·그래프 DB 등 다양한 데이터 소스를 다룰 때 성능 병목과 정확도 저하를 낳는다. 본 논문은 이를 해결하는 다중 에이전트 RAG 시스템을 제안한다. 각 데이터 소스에 최적화된 특화 에이전트들이 관계형·NoSQL·문서 기반 시스템의 질의 생성을 담당하고, 다양한 DB 유형과 호환되도록 설계된 환경에 질의 실행을 위임하며 모듈형 프레임워크 안에서 협업한다. 이 분산 접근은 질의 효율을 높이고 토큰 오버헤드를 줄이며, 각 에이전트가 특화 작업에 집중함으로써 응답 정확도를 개선한다. 확장 가능하고 적응적이어서 다양·동적·사설 데이터 소스 통합이 필요한 생성 AI 워크플로에 이상적이다.

서론: LLM은 정교한 질의 해석과 텍스트 생성으로 NLP를 크게 발전시켰으나, 정적 사전학습 데이터 의존으로 동적·도메인특화·사설 데이터 통합이 제한된다. RAG는 외부 데이터 검색을 생성 과정에 결합해 이를 완화한다. 전통적 RAG는 단일 에이전트가 질의 생성·검색·합성을 모두 맡는 모놀리식 설계로, 관계형 DB·문서 저장소·그래프 데이터 등 다양한 소스에서 스키마·예시·질의를 담은 방대한 프롬프트가 필요해 토큰 비효율·지연·부정확을 낳는다. 이를 극복하기 위해 본 논문은 질의 생성을 각 DB 유형에 특화된 에이전트에게 위임하는 다중 에이전트 RAG를 제안한다. 이 에이전트들은 최적화된 DB별 질의를 생성하되 직접 실행/검색하지 않고, 별도 실행 환경에서 질의를 실행해 다양한 데이터 저장 시스템과 호환을 보장한다. 검색된 컨텍스트는 사용자 원 질의와 결합되어 생성 에이전트가 일관된 응답을 합성한다. 모듈형 설계로 확장성·검색 정확도를 높이고 다중언어(polyglot) 데이터 환경과의 통합을 지원한다.
