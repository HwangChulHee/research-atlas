## 초록+서론 한글 번역
맥락: 수작업 질적 데이터 분석은 시간이 많이 들고 타당성·재현성을 해쳐 분석 설계·구현·보고에 영향을 준다. LLM은 SE에서 인간-봇 협업을 가능케 하나 질적 분석 잠재력은 미탐구다. 목표: 인간 의사결정 지원과 AI를 시너지시켜 다양한 질적 분석 방법을 자동화하는 LLM 기반 멀티에이전트 시스템을 설계·개발한다. 방법: 텍스트 요약·초기 코드 생성·주제와 패턴 추출 등 각기 특정 작업을 맡는 27개 에이전트를 배치했다. 결과: (1) 시스템이 질적 분석 과정을 가속하고, (2) 요약·초기 코딩·주제 추출을 효과적으로 자동화하며, (3) 공개 코드로 검증·평가가 쉽다. 결론: 제안 시스템이 질적 분석을 자동화해 연구자·실무자에게 기회를 연다.

서론: LLM(GPT, Llama)은 NLP·자동 콘텐츠 생성·데이터 분석에서 뛰어나 SE의 여러 작업을 데이터 분석·텍스트 분류 활동으로 전환한다. 질적 데이터 분석에서도 대량 텍스트의 추출·해석을 자동화할 수 있다. 전통 방식은 인간 전문성에 크게 의존하며(인터뷰의 비정형 텍스트를 수작업 코딩·해석), MAXQDA·Nvivo·Atlas.ti·Dedoose·WebQDA·QDAMiner 등도 인간 입력을 요해 시간·전문성이 많이 든다. LLM으로 자동·지능 시스템으로의 패러다임 전환이 일어나고 있으나, 기존 연구(Chew, Dai, Xiao 등)는 주로 주제·내용 분석의 초기 코드 생성에 집중해, 모든 유형의 질적 분석을 자율 수행하는 시스템에는 공백이 있다. 본 논문은 SE에서 가장 널리 쓰이는 다섯 방법(내용·주제·서사·근거이론·담화 분석)을 보조·자동화하는 LLM 멀티에이전트 시스템을 제안한다. 대규모·다양한 데이터셋을 다루고 분석을 가속하며, 수작업 의존을 줄여 효율·접근성을 높인다.
