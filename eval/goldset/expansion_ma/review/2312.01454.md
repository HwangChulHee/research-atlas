# 2312.01454 — D-Bot: Database Diagnosis System using Large Language Models
**한 줄 핵심**: 문서에서 지식을 오프라인 추출하고, 프롬프트 자동 생성·트리 탐색 기반 근본원인 분석에 더해, 복합(다중원인) 이상에 대해 여러 LLM 전문가가 비동기 협업(cross review)하는 LLM 기반 데이터베이스 진단 시스템.
**keep/drop**: keep — 다중원인 이상에 대한 복수 LLM 전문가의 협업 진단 메커니즘(기여 4)을 갖춘 멀티에이전트 협업 방법. (단, MA는 4개 구성요소 중 하나로 부분적 → 경계 플래그.)
**builds_on 초안**: [] (근거: 근본원인 분석의 tree-search 알고리즘은 옵티마이저성 탐색 → D1 제외. SentenceBert는 임베딩 부품 → 제외. XGBoost/KNN/Decision Tree 등은 비교 대상 전통기법 → baseline 제외. 본 방법이 딛고 확장한 named 선행 멀티에이전트/시스템 없음.)
**경계 플래그**: 멀티에이전트 협업은 논문 4개 핵심기법 중 하나이며 시스템 본질은 DB 진단 파이프라인(keep 여부 자체가 경계). tree search(root cause analysis)를 계보로 볼지 애매(D1 인접).

## 초록+서론 한글 번역
데이터베이스 관리자(DBA)는 DB 시스템 관리·유지·최적화에 중요하지만, 수많은 DB를 관리하며 적시에 대응하기는 어렵고 고되다. 기존 경험적 방법은 제한된 진단 시나리오만 지원하며 버전 업데이트마다 규칙 갱신이 노동집약적이다. 이에 D-Bot이라는 LLM 기반 DB 진단 시스템을 제안한다. D-Bot은 진단 문서에서 지식을 자동 획득하고, 합리적이고 근거 있는 진단 리포트(근본원인·해법 식별)를 수용 가능한 시간(예: DBA의 수 시간 대비 10분 이내)에 생성한다. 핵심 기법은 (i) 문서에서 오프라인 지식 추출, (ii) 자동 프롬프트 생성(지식 매칭, 도구 검색), (iii) 트리 탐색 알고리즘 기반 근본원인 분석, (iv) 다중 근본원인 복합 이상을 위한 협업 메커니즘이다. 실제 벤치마크(6개 애플리케이션의 539개 이상)에서 D-Bot은 미지의 이상 근본원인을 효과적으로 분석하며 전통 방법과 vanilla GPT-4를 크게 능가한다.

서론: DB 진단은 이상 이벤트를 탐지·분석·해결하는 과제다. DB 이상은 매우 다양해 사전 규칙으로 포괄 불가능하다(한 벤더는 3개월간 900건 이상 이상 경험). 많은 기업은 인간 DBA에 의존하며, 진단 과정은 알림 탐지→메트릭 분석→이벤트 분석→최적화 조언으로 이어지는 반복적 절차다. 그러나 DBA 양성은 오래 걸리고 인력 확보·적시 대응이 어렵다. 기존 반자동 도구는 경험 규칙이나 소규모 ML 분류기(Decision Tree, MLP, RNN, XGBoost, KNN 등)로 만들어져 시나리오 이해력이 낮고 일반화가 어렵고 추론 능력이 없다.

최근 LLM은 이 목표 달성의 잠재력을 보이지만, DB 진단은 도메인 전문 기술이 필요해 GPT-4조차 직접 마스터하지 못한다(정확도 50% 미만). 세 가지 도전: (C1) LLM의 진단 문제 이해 향상(문서에서 지식 추출·매칭, 도구 검색), (C2) 단일원인 이상 진단 성능 향상(조기 종료·환각 문제), (C3) 다중원인 이상 진단 능력 향상 — 단일 LLM은 복합 이상을 정확히 분석하기 어려우므로 여러 LLM이 협업(cross review)으로 복잡한 DB 문제를 다루는 효율적 진단 메커니즘 설계가 관건이다. 이를 위해 D-Bot을 제안한다: (1) 요약-트리 기반 지식 추출과 계층적 도구 구성, (2) 관련 지식·도구 매칭 프롬프트 생성(fine-tuned SentenceBert), (3) 과거 시도를 반성하며 유망한 경로를 고르는 트리 탐색 전략, (4) 복합 이상에 대해 여러 LLM 전문가가 비동기적으로(분석 결과 공유, cross review) 협업 진단하는 메커니즘.
