# 2312.03664 — Generative agent-based modeling with actions grounded in physical, social, or digital space using Concordia

**한 줄 핵심**: LLM 기반 Generative Agent-Based Model(GABM)을 구축·운용하는 라이브러리 Concordia로, 태블톱 RPG의 '게임 마스터(GM)'가 환경을 시뮬레이션하고 자연어 행동을 구현으로 번역한다.

**keep/drop**: keep — 다중 생성 에이전트 + GM 오케스트레이션이 본질인 다중 에이전트 시뮬레이션 프레임워크/라이브러리.

**builds_on 초안**: [] (없음)
- 근거: Agent-Based Modeling(ABM)의 진화형으로 자리매김하나 ABM은 느슨한 방법 범주어 → D4 제외. Generative Agents(개념)를 토대로 하나 명시적 named 기법 계보 확장 서술은 약함. GM은 태블톱 RPG에서 '영감'(기법 아님). 명명된 선행 기법을 딛고 확장한 구체 서술 없음.

## 초록+서론 한글 번역
에이전트 기반 모델링(ABM)은 수십 년간 사회·자연과학에 널리 쓰여 왔다. 이제 LLM이 제공하는 새로운 기능을 흡수하며 이 연구 방법의 범위가 극적으로 확장될 참이다. Generative Agent-Based Model(GABM)은 단지 에이전트끼리 대화하는 고전 ABM이 아니라, LLM을 사용해 상황에 상식을 적용하고 "합리적으로" 행동하며 공통 의미지식을 회상하고 디지털 기술을 제어하는 API 호출을 만들고 시뮬레이션 내·외부와 소통하도록 구성된다. 본 논문은 GABM 구축·운용을 돕는 라이브러리 Concordia를 제시한다. 물리적·디지털로 접지된 환경의 언어 매개 시뮬레이션을 쉽게 구성하게 한다. Concordia 에이전트는 두 근본 연산(LLM 호출과 연상 기억 검색)을 매개하는 유연한 컴포넌트 시스템으로 행동을 생성한다. 태블톱 롤플레잉에서 영감을 받은 특수 에이전트 게임 마스터(GM)가 에이전트들이 상호작용하는 환경을 시뮬레이션한다. 에이전트는 하고 싶은 것을 자연어로 기술하고, GM은 이를 적절한 구현으로 번역한다. 물리 세계에서는 GM이 행동의 물리적 타당성을 확인·기술하고, 디지털 환경에서는 외부 도구(AI 비서, 앱)와 통합하는 API 호출을 처리할 수 있다. Concordia는 과학 연구와, 사용자 시뮬레이션·합성 데이터 생성을 통한 실제 디지털 서비스 성능 평가 등 폭넓은 응용을 지원하도록 설계되었다.

서론(발췌): 에이전트 기반 사회 시뮬레이션은 사회·자연과학 전반에 쓰인다. 역사적으로 ABM은 비교적 추상적 분석 수준에 적용되어 유용성이 제한되었다. 예컨대 행동경제학의 통찰을 (이하 원문 잘림).
