## 초록+서론 한글 번역
유전자 발현 분석은 많은 생의학적 발견의 열쇠이지만, 여러 대용량·반정형 파일의 복잡성과 방대한 도메인 전문성 요구 때문에 원시 전사체 데이터에서 통찰을 뽑기는 여전히 어렵다. 현재 자동화 접근은 엣지 케이스에서 무너지는 경직된 워크플로거나, 엄밀한 과학적 탐구에 필요한 정밀성이 부족한 완전 자율 에이전트에 그친다. GenoMAS는 구조화된 워크플로의 신뢰성과 자율 에이전트의 적응성을 통합한 LLM 기반 과학자 팀을 제시함으로써 다른 길을 택한다. GenoMAS는 여섯 개 전문 LLM 에이전트를 타입드 메시지 패싱 프로토콜로 오케스트레이션하며, 각자가 공유 분석 캔버스에 상보적 강점을 기여한다. 핵심에는 guided-planning 프레임워크가 있어, 프로그래밍 에이전트가 고수준 과제 지침을 Action Unit으로 펼치고 각 분기점에서 전진·수정·건너뛰기·되돌리기를 선택해 논리적 일관성을 유지하면서 유전체 데이터의 특이성에 유연하게 대응한다. GenoTEX 벤치마크에서 데이터 전처리 Composite Similarity Correlation 89.13%, 유전자 식별 F1 60.48%로 기존 최고 대비 각각 10.61%, 16.85% 향상했다.

서론: 과학 연구는 복잡한 계산 분석에 점점 의존하나, 그 설계·실행은 노동집약적·오류취약하고 확장이 어렵다. 유전체학·재료·신약·역학·맞춤의학 등에서 분석의 근간은 코드로 작성된 고도로 구조화된 다단계 워크플로다. 최근 LLM은 과제 분해·도구 사용·실행 코드 생성이 가능한 범용 에이전트로 급성장해, 분석 파이프라인 자동화로 과학 발견에 기여할 가능성을 열었다. 그러나 일반 추론력과 과학 계산의 구조화·정밀 요구 사이의 근본 간극을 메워야 한다. 많은 LLM 에이전트가 문서 검색·API 호출·추상 과제 계획에는 능하지만, 과학적 진보가 코드에 의존하는 영역(전사체학·단백질 공학·통계유전학)에서는 부족하다. 이런 워크플로는 데이터·모델 가정·실험 설계의 특이성에 맞춘 프로그램 변환의 연쇄이며, 분석가는 손상된 메타데이터 처리·교란변수 보정·폐기된 식별자 매핑·통계절차 재구현 등을 위해 맞춤 스크립트를 작성한다. 이런 작업은 선언적 그래프로 추상화하거나 블랙박스 도구에 위임할 수 없고 직접 편집 가능한 코드를 요구한다. 대부분 멀티에이전트 프레임워크는 도구 호출 조합·검색 함수 랭킹·구조화 그래프 상 모듈 호출 조율로 작동하며, 동적 라우팅·온도 튜닝·신경 모듈 선택을 지원해도 고정 아키텍처 템플릿 내에서만 동작한다. 일부는 코드 수준 제어를 시도하나 구조화된 수정 메커니즘·검증 계층·도메인 인식 교정이 없고, 합성 과제로 벤치마크되어 과학적 타당성이 아닌 출력 형식·도구 호환성으로 평가된다. 유전자 발현 분석 같은 도메인에서는 전처리·모델 선택의 작은 오류도 결과를 무효화한다. 이에 저자들은 과학 에이전트를 워크플로 오케스트레이터일 뿐 아니라 협업 프로그래머로 재정의하는 GenoMAS를 제시한다. 도구 호출·템플릿 연쇄 대신, GenoMAS 에이전트는 각 과제에 맞춘 실행 코드를 생성·수정·검증한다. GenoTEX(1,384개 유전자-형질 연관 과제) 벤치마크에서 원시 데이터만으로 SOTA를 달성한다. 기여: (1) 에이전트를 도구 오케스트레이터가 아닌 협업 프로그래머로 다뤄 종단간 코드 생성을 가능케 하는 멀티에이전트 프레임워크, (2) 워크플로를 편집 가능한 Action Unit으로 인코딩하는 guided planning 메커니즘, (3) 상이 강점의 이질적 LLM을 조율된 역할로 조합하는 이질적 에이전트 구성 지원.
