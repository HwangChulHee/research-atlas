# 2307.06187 — Self-Adaptive Large Language Model (LLM)-Based Multiagent Systems

**한 줄 핵심**: 자율컴퓨팅의 자기적응(self-adaptation) 패러다임에 LLM(GPT-4) 통신 능력을 결합해, MAPE-K 제어루프 위에서 자기적응하는 멀티에이전트 시스템을 제안.

**keep/drop**: keep — 멀티에이전트 시스템의 자기적응·에이전트 간 통신을 본질로 하는 방법/패러다임 논문. (경계: 비전성 짙고 "기본 MAS 응용"으로만 예시 검증하는 얇은 방법 논문이라 borderline.)

**builds_on 초안**: [MAPE-K] (근거: "We anchor our methodology on the MAPE-K model"으로 모니터-분석-계획-실행 제어루프를 방법의 뼈대로 명시적으로 딛음 → D2 계보. GPT-4는 백본이라 제외, 저자들의 진화 신경망 기반 이전 통신 방식은 self라 제외.)

**경계 플래그**: 없음(MAPE-K는 자율컴퓨팅 참조모델로 명확한 계보. 프레임워크 인용 애매성 없음.)

## 초록+서론 한글 번역
자율컴퓨팅에서 자기적응은 멀티에이전트 시스템(MAS)의 복잡성을 관리하는 근본 패러다임으로 제안되어 왔으며, 시스템이 스스로를 모니터링·적응하도록 확장한다. 에이전트 상호작용 시 통신은 직접적·명확한 정보교환으로 협력을 높이고 조정 문제를 줄이는 핵심이다. 그러나 MAS 상호작용 통신의 표현력을 높이는 것은 쉽지 않다. 본 논문은 GPT 기반 LLM을 MAS에 통합하는 것을 제안하고, 동적 환경에 대한 적응을 모니터링·분석·계획·실행으로 지원하는 MAPE-K 모델에 방법을 정박한다. 기본 MAS 응용을 구현·평가하는 실증 예시도 제시하며, LLM 능력 기반 MAS 자기적응이라는 새 패러다임으로 자기적응 시스템의 최신 수준을 진전시킨다.

서론: 자기적응 MAS 개발은 복잡한 과제다. 통신이 핵심이며, 기본 통신 구성만으로도 단순 에이전트가 견고한 집단행동을 낼 수 있고, 복잡한 과제는 적응행동의 창발을 유발한다. 그러나 표현력 향상은 동기화 오버헤드 등 도전을 낳아 연구자들은 단순 통신에 의존해 왔다. LLM/GPT의 급속한 발전은 적은 자원으로 고도의 대화형 통신을 소프트/하드웨어 에이전트에 통합할 길을 연다. 본 논문은 GPT 기반 LLM을 MAS에 통합하는 패러다임을 제안하고, 처음부터 강력한 통신 시스템을 갖춘 에이전트의 창발 능력을 탐구한다. 진화 신경망으로 통신을 스스로 진화시킨 이전 접근과 달리, 시작부터 능력을 갖춘 패러다임 전환을 탐색한다. 방법은 LLM 기반 MAPE-K 모델에 기반하며 GPT-4를 통합해 복잡한 과제 적응과 지능적 반응을 가능케 한다.
