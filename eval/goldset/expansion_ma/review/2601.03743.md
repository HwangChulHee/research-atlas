# 2601.03743 — O-Researcher: An Open Ended Deep Research Model via Multi-Agent Distillation and Agentic RL

**한 줄 핵심**: 협업 AI 에이전트들이 도구 통합 추론을 시뮬레이션해 연구급 지시 데이터를 자동 합성하는 다중 에이전트 워크플로와, 그 데이터로 오픈소스 딥리서치 모델을 만드는 2단계 학습(SFT + 신규 RL) 프레임워크를 제안한다.

**keep/drop**: keep — 다중 에이전트가 분해·토론·검증으로 협업하는 데이터 합성 워크플로가 핵심 기여. (경계: 최종 산출물 O-Researcher는 단일 에이전트 모델이며, 멀티에이전트는 데이터 합성 단계에만 존재 → 단일에이전트 판정 여지)

**builds_on 초안**: [] (근거: RL 방법은 D1 옵티마이저 제외. 차트의 딥리서치 모델/에이전트들(GPT-5, Gemini-2.5-Pro, MiroThinker, WebWeaver 등)은 점수 비교 baseline이라 제외. 초록+서론에 이 논문의 다중 에이전트 워크플로가 딛고 확장한 특정 named 선행 시스템 없음. distillation/SFT는 일반 기법)

**경계 플래그**: 멀티에이전트 협업이 '추론 시점의 시스템'이 아니라 '학습 데이터 합성 워크플로'에만 존재하고, 배포되는 O-Researcher는 단일 모델이라 keep/drop 경계. (형제 논문 Chain-of-Agents 계열의 multi-agent distillation 패턴)

## 초록+서론 한글 번역
폐쇄형과 오픈소스 LLM의 성능 격차는 대체로 고품질 학습 데이터 접근성 차이에 기인한다. 이 격차를 메우기 위해, 정교한 연구급 지시 데이터를 자동 합성하는 새로운 프레임워크를 제안한다. 핵심은 협업 AI 에이전트들이 복잡한 도구 통합 추론을 시뮬레이션해 다양하고 고충실도의 데이터를 종단간(end-to-end) 생성하는 다중 에이전트 워크플로다. 이 합성 데이터를 활용해, 지도 파인튜닝(SFT)과 새로운 강화학습 방법을 통합한 2단계 학습 전략으로 모델 정렬과 능력을 극대화한다. 광범위한 실험으로 이 프레임워크가 여러 규모의 오픈소스 모델을 주요 딥리서치 벤치마크에서 새로운 SOTA로 끌어올림을 보인다. 독점 데이터/모델 없이 오픈소스 LLM을 발전시키는 확장 가능한 경로를 제시한다.

서론: LLM의 급속한 발전은 현대 AI의 초석이 되었으나, 강력한 폐쇄형 모델(GPT-4o, OpenAI o1)과 오픈소스 모델 간 성능 격차가 지속된다. 이는 방대한 독점 고품질 데이터와 막대한 계산 자원 때문이며, 특히 긴 사고 사슬과 엄밀한 문제 해결을 요하는 추론 집약 과제에서 두드러진다. 이 병목을 넘는 핵심 경로는 SFT·RL용 고품질·다양·확장 가능한 지시 데이터 생성이다. 기존 방법(인간 주석, 큰 교사 모델 증류)은 비싸거나 규모가 제한적이거나 교사의 한계를 물려받으며, 표준 증류는 최종 답만 포착해 복잡 문제 해결의 '사고 과정' 전이에 실패한다. 따라서 방대·정교한 연구급 데이터를 합성하는 자동 종단간 프레임워크가 절실하다. 본 논문은 다중 에이전트 기반 합성 데이터 생성 워크플로로 이 문제를 다룬다. 핵심 통찰은 특화 AI 에이전트들의 협업 생태계가 엄격한 동료 심사와 유사하게 인간 추론 과정을 자율 시뮬레이션해 고충실도 다중턴 지시-응답 쌍을 만든다는 것이다. 이 합성 데이터는 2단계 학습(SFT로 강한 지식 기반 확립 → RL로 성능·자기수정 정제)의 토대가 된다. 기여: (1) 분해·토론·검증하는 다중 LLM 에이전트 협업 워크플로로 종단간 딥리서치 데이터를 자동 합성, (2) 신규 RL을 포함한 2단계 학습 전략, (3) 여러 크기의 오픈소스 모델을 딥리서치 벤치마크에서 SOTA로 향상.
