## 초록+서론 한글 번역
대형 언어 모델(LLM)은 최근 언어 생성, 이해, few-shot 학습에서 뛰어난 능력을 보였다. 프롬프팅(검증, self-consistency, 중간 스크래치패드 등) 도구로 성능을 더 끌어올리려는 방대한 연구가 있었는데, 이들은 모두 단일 모델 인스턴스에 적용된다. 본 논문은 이를 보완하는 접근으로, 여러 언어 모델 인스턴스(에이전트)가 각자의 답과 추론 과정을 제안하고 여러 라운드에 걸쳐 토론(debate)하여 하나의 공통 최종 답에 도달하는 방법을 제시한다.

구체적으로 질의가 주어지면 여러 모델 인스턴스가 먼저 개별 후보 답을 생성하고, 이후 각 인스턴스가 다른 모델들의 응답을 읽고 비평하여 자신의 답을 갱신한다. 이 단계를 여러 라운드 반복한다. 이 방법은 The Society of Mind와 멀티에이전트 설정에서 영감을 받았다. 실험 결과 수학·전략적 추론에서 성능이 크게 향상되고, 생성 내용의 사실성(factuality)이 개선되어 환각과 오답이 줄었다.

이 방법은 zero-shot chain-of-thought[11], reflection[26,18] 같은 단일 모델 baseline을 능가한다. 여러 에이전트와 여러 라운드를 함께 쓰는 것이 최고 성능에 중요하다. 같은 모델 클래스라도 초기에는 다양한 답이 나오며(다른 모델 유형인 ChatGPT와 Bard를 섞는 경우도 조사), 토론 후 집단은 거의 항상 더 정확한 하나의 답으로 수렴한다. 방법은 블랙박스 접근만 필요하며(내부 확률·gradient 불필요), retrieval이나 프롬프트 엔지니어링과 직교적으로 결합 가능하다. 토론은 비용이 크지만 답 품질을 크게 높이고, 추가 학습 데이터 생성으로 자기개선 루프를 만들 수 있다. 또한 유명 컴퓨터과학자 전기의 사실성을 평가하는 새 벤치마크를 도입한다.
