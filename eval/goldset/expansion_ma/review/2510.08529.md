## 초록+서론 한글 번역
자기진화(self-evolution)는 LLM 기반 에이전트가 사전학습 이후에도 능력을 지속 향상시키게 하는 핵심 연구 주제다. 최근 연구는 RL-free에서 RL 기반 방법으로 전환되어 왔다. 현재 RL 기반 방법은 조밀한 외부 보상 신호에 의존하거나 LLM 자체에서 내재적 보상 신호를 추출한다. 그러나 이 접근들은 인간 지능에서 관찰되는 자기진화 메커니즘, 즉 상호 토론·협력을 통한 학습·향상과는 거리가 있다. 본 연구는 외부 감독 없이 에이전트 간 상호작용에서 학습해 자율적으로 향상되는 신규 프레임워크 Co-Evolving Multi-Agent Systems(CoMAS)를 제안한다. CoMAS는 풍부한 토론 동역학에서 내재적 보상을 생성하고, LLM-as-a-judge 메커니즘으로 이 보상을 형성하며, RL로 각 에이전트 정책을 최적화해 탈중앙·확장 가능한 공진화를 실현한다. 실험 결과 CoMAS는 미학습 에이전트를 일관되게 능가하고 대부분 평가 설정에서 SOTA를 달성했다. 절제 연구는 상호작용 기반 보상 신호의 필요성을 확인하고, 에이전트 수·다양성 증가에 따른 유망한 확장성을 보였다.

자기진화는 LLM 기반 에이전트의 핵심 주제로, 사전학습 후 정체되지 않고 환경과의 상호작용으로 능력을 지속 향상시키는 것을 목표로 한다. 초기 탐구는 주로 RL-free 전략—외부 지식베이스 확장, 다수 에이전트 앙상블, 과제 워크플로 최적화, 심볼릭 학습—을 채택했다. 그러나 이들의 효과는 기반 모델의 고정된 능력에 본질적으로 제약된다. 이후 에이전트 파인튜닝 기법이 도입되었으나 진정으로 지속적·부트스트래핑적 진화적 향상을 지원하기엔 부족하다. RL은 이 한계를 넘는 유망한 방향을 제시하며, 보상 신호의 출처로 분류할 수 있다. 대다수 기존 접근은 rule-based verifier나 특화 reward model에서 나오는 외부 보상에 의존한다. 최근에는 내재적 보상을 탐구해 외부 감독을 없애고 내부 신호를 활용하는데, self-certainty, confidence, semantic entropy, majority voting 유사 라벨 등의 메커니즘으로 저확률 영역을 피하거나 고신뢰 예측을 강화한다. 이는 외부 보상이 전제조건이 아닌 자기진화의 길을 연다. 그러나 RL 기반 방법들의 설계는 여전히 개별 모델 수준의 self-rewarding에 집중되어, 다양성·상호작용에서 창발하는 집단적 현상으로서의 인간 지능과 대비된다. 인간 팀에서 개인은 외부 오라클 없이 상호 토론·협력으로 학습·향상한다. 이 대비가 핵심 질문을 촉발한다: LLM 기반 에이전트도 인간처럼 외부 보상 없이 순수하게 에이전트 간 상호작용에서 학습해 자기진화할 수 있는가? 이를 위해 에이전트가 상호작용에서 학습해 자율 향상하는 신규 프레임워크 CoMAS를 제안한다. CoMAS는 세 핵심 구성요소로 이루어진다: 첫째, interaction은 해법 제안·평가·채점으로 구조화된 협력적·비판적 토론으로 풍부한 대화 데이터를 생성한다. 둘째, reward formulation은 LLM-as-a-judge로 이 토론 이력에서 직접 내재적 보상 신호를 도출한다. 셋째, policy optimization은 RL로 각 에이전트 정책을 갱신해 상호작용 데이터의 교훈을 내재화한다. CoMAS의 이점: (1) 상호작용에서 내재적으로 보상 생성(verifier·reward model 불필요), (2) 검증 어려운 개방형 문제 포함 다양한 과제에 일반적으로 효과적, (3) 탈중앙 학습으로 공유 모델 병목 없이 이질 시스템 공진화, (4) out-of-domain 과제·다양한 협업 설정으로 전이되는 기술 육성. Vanilla·Consistency·AutoGen·Debate 설정에서 미학습 대비 최대 2.20%·3.66%·19.80%·6.10% 절대 향상을 달성했다.
