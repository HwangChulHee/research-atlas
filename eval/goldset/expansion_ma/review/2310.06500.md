# 2310.06500 — MetaAgents: Simulating Interactions of Human Behaviors for LLM-based Task-oriented Coordination via Collaborative Generative Agents

**한 줄 핵심**: LLM 기반 에이전트들이 스스로 팀을 구성(team assembly)하고 역할·스킬을 매칭하는 능력을 조사하기 위한 사회 시뮬레이션 프레임워크(잡페어 사례 연구).

**keep/drop**: keep — LLM 에이전트의 팀 구성·협업 조정(coordination)이 본질인 다중 에이전트 프레임워크 방법.

**builds_on 초안**: [ChatDev, MetaGPT] (근거)
- ChatDev, MetaGPT: 본문에서 "대표적 다중에이전트 프레임워크"로 명시하고, "이들은 인간이 미리 규정한 팀 구성·워크플로에 묶여 자율 팀 구성 능력이 없다. 이 한계는 에이전트가 스스로 팀을 구성하는 시스템을 설계함으로써 극복될 수 있다"고 서술 → D2(한계 지적 → 그 위에서 확장). MetaAgents는 이들의 고정 팀구성 한계를 자율 팀 조립으로 확장.

**경계 플래그**: Generative Agents(Park et al.) — MetaAgents가 generative agent 아키텍처를 토대로 함(제목·키워드에 등장)이나 명시적 계보 확장 서술은 약해 계보로 볼지 애매.

## 초록+서론 한글 번역
LLM의 사회 시뮬레이션 응용은 크게 발전했으나, 과제 지향 사회 이벤트에서의 '팀 구성(teaming)' 능력은 덜 탐구되었다. LLM이 인간적 사회 행동을 모사하고 효율적 팀을 꾸려 과제를 풀려면 이런 능력이 중요하다. 이를 메우기 위해 LLM 기반 에이전트로 채워진 사회 시뮬레이션 프레임워크 MetaAgents를 도입한다. 에이전트들이 사회적 맥락에서 대화하고 일련의 의사결정을 하게 하여 상호작용과 대인 의사결정을 조사하는 플랫폼이다. 특히 잡페어(job fair) 환경을 사례로 구성해 LLM 에이전트의 팀 조립·스킬 매칭 행동을 정량·정성 분석한다. 평가 결과 LLM 에이전트가 효율적 팀을 만드는 합리적 결정을 잘 수행하나, 더 복잡한 팀 조립 과제에서는 효과를 제한하는 한계도 확인했다.

서론: LLM은 텍스트 생성을 넘어 대화·의사결정·과제완수가 가능한 다재다능 에이전트로 자리매김했다. 아직 덜 탐구된 영역이 LLM 에이전트의 사회 지능—팀 조직과 역할-전문성 정렬이다. 선행 다중에이전트 연구는 주로 과제해결 능력에 집중했고, 대표적으로 ChatDev와 MetaGPT는 사전 규정된 워크플로·팀 구성 안에서 에이전트가 역할을 수행하는 자율 소프트웨어 개발 프레임워크다. 그러나 이들은 인간이 규정한 팀 구성·워크플로에 묶여 자율 팀 조립 능력이 없어 적응성이 제한된다. 이 한계는 에이전트가 처음부터 스스로 팀을 구성하는 시스템으로 극복될 수 있다. 그렇다면 LLM 에이전트가 사회 맥락에서 적절한 위치에 에이전트를 배치하며 팀 구성을 할 수 있는가? 이를 잡페어 시나리오로 조사하기 위해 MetaAgents를 도입한다. 다중턴 대화와 순차적 의사결정으로 사회적으로 연결된 에이전트들이 스킬·배경에 따라 책임을 배정받는 팀 조립·워크플로 설계 과정을 연구한다.
