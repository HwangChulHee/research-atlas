# 2402.16823 — GPTSwarm: Language Agents as Optimizable Graphs

**한 줄 핵심**: LLM 에이전트를 계산 그래프(노드=연산, 엣지=정보흐름)로 통일 표현하고, 노드(프롬프트)와 엣지(오케스트레이션 연결성)를 자동으로 최적화하는 프레임워크.

**keep/drop**: keep — 다중 에이전트 오케스트레이션(엣지 최적화로 협업 토폴로지 개선)이 본질인 방법 논문.

**builds_on 초안**: [] (없음)
- 근거: CoT/ToT/Self-Consistency/ReAct/Reflexion/GoT를 그래프로 '표현·재조합'하지만 이는 방법을 얹은 계보가 아니라 통일 표현 대상(D3 대비/표현). AutoGPT/BabyAGI/LangChain은 단일에이전트 배경. GPTSwarm의 방법(그래프 최적화)은 이들을 딛고 확장한 것이 아님.

**경계 플래그**: Society of Mind(Minsky) — "SOM에서 영감을 받아 언어 에이전트를 그래프로 기술"이라는 개념적 계보. 그러나 SoM은 인지이론(named 기법/시스템이 아님)이라 계보로 볼지 애매. ToT/Reflexion 등은 엣지 최적화로 재조합되는 대상으로, 계보(D2)가 아닌 표현 대상으로 처리.

## 초록+서론 한글 번역
LLM 기반 문제해결기를 개선하려 다양한 인간설계 프롬프트 엔지니어링 기법이 제안되며 서로 이질적인 코드베이스가 양산되었다. 우리는 LLM 기반 에이전트를 계산 그래프로 기술해 이 접근들을 통일한다. 노드는 멀티모달 데이터를 처리하거나 LLM을 질의하는 함수를 구현하고, 엣지는 연산 간 정보 흐름을 기술한다. 그래프는 재귀적으로 더 큰 합성 그래프로 결합되어 에이전트 간 협업 위계를 표현한다(엣지가 서로 다른 에이전트의 연산을 연결). 우리의 새로운 자동 그래프 옵티마이저는 (1) 노드 수준 LLM 프롬프트를 정제(노드 최적화)하고 (2) 그래프 연결성을 바꿔 에이전트 오케스트레이션을 개선(엣지 최적화)한다. 실험은 이 프레임워크가 다양한 LLM 에이전트를 효율적으로 개발·통합·자동개선함을 보인다.

서론: LLM 자율 문제해결기(에이전트)에 대한 관심이 커지지만, 이들을 하나의 사회로 통합하고 구조를 자동 개선하는 일은 많이 남아 있다. 초기 접근은 zero-shot 또는 few-shot 프롬프트였고, 최근은 CoT, ReAct, ToT, Reflexion, Graph of Thought(GoT) 등 구조화된 프롬프트로 추론을 개선한다. AutoGPT/BabyAGI/LangChain/Llama-index 같은 단일 에이전트 응용은 도구 사용·함수 호출·체화 행동에 LLM을 활용한다. 다중 에이전트 프레임워크에서는 여러 LLM이 서로 다른 역할을 맡아 자연어로 소통하며 협력해 과제를 풀고, 이는 흔히 단일 에이전트를 능가한다. 그러나 이는 이질적 코드베이스와 많은 인간 엔지니어링을 낳는다. Minsky의 "Society of Mind(SOM)"에서 영감을 받아, 우리는 언어 에이전트 시스템을 그래프 표현으로 기술한다. 노드는 특정 함수, 엣지는 노드 간 입력 처리 토폴로지이며, swarm은 각 부분그래프가 협업 에이전트인 합성 그래프다. CoT/ToT/Self-Consistency도 우리의 그래프로 표현 가능하다. 이 그래프 표현은 프롬프트·진화·강화학습 기법을 통한 최적화에 적합하여, 엣지 최적화로 ToT·Reflexion 등 기존 기법을 자동 재조합하고, 각 노드가 프롬프트를 스스로 개선하게 한다. 기여: (1) 언어 에이전트 시스템을 최적화 가능한 계산 그래프로 통일, (2) 오픈소스 프레임워크 제공, (3) 노드·엣지 최적화 방법 개발, (4) MMLU/CrossWords/HumanEval/GAIA 등에서 검증.
