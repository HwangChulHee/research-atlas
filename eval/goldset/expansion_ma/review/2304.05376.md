# 2304.05376 — ChemCrow: Augmenting large-language models with chemistry tools

**한 줄 핵심**: GPT-4 단일 LLM에 18개 전문가 설계 화학 도구를 붙여 유기합성·신약·소재 과제를 자율 계획·실행하게 만든 화학 에이전트.

**keep/drop**: drop — 단일 LLM 에이전트가 도구를 호출하는 tool-augmented 방식(ReAct 루프)일 뿐, 여러 에이전트의 협업/오케스트레이션이 아니다. 멀티에이전트 아님.

**builds_on 초안**: [ReAct, MRKL] (근거: 본문에서 "This workflow, previously described in the ReAct and MRKL papers"라며 Thought/Action/Observation 추론-도구 루프를 이 두 기법 위에 그대로 세웠다고 명시 → D2 계보. GPT-4/GPT-3.5는 백본이라 제외, OPSIN·RXN·AIZynthFinder는 도구라 제외.)

**경계 플래그**: chain-of-thought(CoT) — 본문이 "combines chain-of-thought reasoning with tools"라며 명시적으로 딛지만 매우 일반적 프롬프팅 기법이라 계보 포함 여부 애매(D3/D4 경계). 이 논문 자체는 drop이므로 계보는 참고용.

## 초록+서론 한글 번역
지난 수십 년간 뛰어난 계산화학 도구들이 개발되었으나, 가파른 학습 곡선 탓에 잠재력을 다 발휘하지 못했다. LLM은 여러 도메인에서 강력하지만 화학 문제에 약하고 외부 지식원에 접근하지 못한다. 본 연구는 유기합성·신약·소재 설계 과제를 수행하도록 설계된 LLM 화학 에이전트 ChemCrow를 소개한다. 18개 전문가 설계 도구를 통합해 화학 성능을 증강하고 새로운 능력이 창발한다. 우리 에이전트는 방충제, 세 개의 유기촉매 합성을 자율 계획·실행하고 새로운 발색단 발견을 유도했다. GPT-4를 평가자로 쓰면 명백히 틀린 GPT-4 응답과 ChemCrow 성능을 구별하지 못한다는 점도 발견했다.

서론: LLM은 자연어 작업을 자동화해 왔고(GitHub Copilot, StarCoder), Transformer 기반의 few/zero-shot 성능을 보인다. 그러나 기초 수학·화학 연산에 약하다. 이를 보완하는 한 방법은 계산기나 OPSIN(IUPAC→구조 변환) 같은 외부 도구/플러그인으로 LLM을 증강하는 것이다. 화학은 반응예측·역합성·물성예측·분자생성 등 전문가 설계 AI로 다뤄져 왔으나 도구들의 통합·상호운용이 실험화학자에게 어렵다. 우리는 GPT-4에 도구 목록과 설명을 주고 ReAct의 Thought/Action/Action Input/Observation 형식으로 추론·도구호출을 반복시키는 ChemCrow를 제안한다. 이 워크플로는 ReAct와 MRKL 논문에서 서술된 방식으로, CoT 추론과 도구를 결합한다. 웹·문헌 검색, 분자·반응 도구 등 18개를 구현해 물리 실험실 작업까지 직접 수행할 수 있게 했다.
