# 2311.13884 — Controlling Large Language Model-based Agents for Large-Scale Decision-Making: An Actor-Critic Approach (LLaMAC)
**한 줄 핵심**: 중앙집중식 크리틱(TripletCritic)이 다수 액터를 조율하고 내·외부 피드백으로 반복 추론하는, 액터-크리틱 RL에서 착안한 대규모(최대 50+) LLM 멀티에이전트 의사결정 프레임워크(LLaMAC).
**keep/drop**: keep — 대규모 LLM 에이전트 간 조율·오케스트레이션(중앙 크리틱-분산 액터, 토큰 효율적 협업)이 본질인 방법 프레임워크.
**builds_on 초안**: [] (근거: 서론이 명시적으로 딛는 것은 "classical actor-critic reinforcement learning approach [Konda and Tsitsiklis, 1999]"와 뇌의 분포적 가치 부호화[Dabney 2020]로, 전자는 RL 알고리즘/옵티마이저 계열(D1 제외), 후자는 신경과학 착안이라 LLM 기법 아님. role-playing(CAMEL)·debate(ChatEval) 등은 대조군으로 인용될 뿐 확장 대상 아님.)
**경계 플래그**: "actor-critic (RL)" — LLaMAC의 이름·구조(액터/크리틱)를 직접 규정하는 착안원이지만, D1 옵티마이저(PPO 등이 속한 RL 알고리즘 계열) 규칙상 제외. 아키텍처적 착안(옵티마이저로 학습에 쓴 것 아님)이라 계보 편입 여부 애매—기록.

## 초록+서론 한글 번역
LLM의 발전은 멀티에이전트 시스템(MAS)의 계획·의사결정 문제 해결에 새 길을 연다. 그러나 에이전트 수가 늘수록 LLM의 환각과 MAS의 조율 문제가 두드러지고, 다수 에이전트 상호작용을 LLM으로 촉진할 때 토큰의 효율적 사용이 핵심 고려사항이 된다. 본 논문은 이를 완화하는 모듈형 프레임워크 LLaMAC을 개발한다. LLaMAC은 인간 뇌에서 발견되는 것과 유사한 가치 분포 부호화를 구현하며, 내·외부 피드백 메커니즘으로 모듈 간 협업과 반복 추론을 촉진한다. 시스템 자원 할당과 로봇 그리드 운송 평가를 통해 제안 방식의 상당한 이점을 입증한다.

서론: 방대한 데이터로 학습된 LLM은 상당한 추론 능력을 보이며, CoT 같은 프롬프팅으로 추론·계획 능력이 증강된다. 최근 NLP·MAS 분야에서 다수 LLM 기반 에이전트의 협업적 문제 해결이 활발히 탐구되며, role-playing[Li et al. 2023]과 debate[Chan et al. 2023]로 시너지·조율을 도모한다. 그러나 대부분 기존 연구는 소수 에이전트 조율에 국한되고(표 1), 대규모 에이전트 시나리오에서의 LLM 조율은 거의 다뤄지지 않았다. 이는 대규모 다중에이전트 의사결정의 복잡도가 크게 증가하기 때문이다. 저자들은 세 핵심 도전에 주목한다: (1) 에이전트 수 증가 시 결합 행동공간의 지수적 증가, (2) LLM 자체의 환각으로 인한 의사결정 신뢰성 저하, (3) 대규모 LLM 에이전트 시나리오에서의 토큰·통신 자원 관리. 이를 위해 고전적 액터-크리틱 RL[Konda & Tsitsiklis 1999]에서 착안한 LLaMAC을 제시한다. 중앙집중식 크리틱이 코디네이터 역할로 각 액터의 결정 메모리에 근거해 제안을 하고, 액터들은 환경과 상호작용하며 과제를 수행한다. 주요 기여: (1) 뇌의 분포적 가치 부호화[Dabney 2020]에서 착안한 TripletCritic 구조로 공유 목표·상이 선호를 가진 다수 크리틱을 내부 피드백으로 조율, (2) 액터와 TripletCritic 간 외부 피드백 메커니즘으로 LLM 접근 비용 절감·독립 탐색 유지, (3) 대규모 환경에서 LLM 에이전트 의사결정을 증강하는 모듈형·토큰 효율적 프레임워크. 시스템 자원 할당·로봇 그리드 운송에서 최종 성능·토큰 효율·정책 안정성 모두 기존을 능가하며, 50개 초과 에이전트의 대규모 다중에이전트 의사결정에 LLM을 적용한 최초 사례라 주장한다.
