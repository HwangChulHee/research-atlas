**keep/drop**: keep — 다중 LLM 에이전트의 역할 분업과 협업(analyst→coder→tester 피드백 루프)이 방법의 본질인 멀티에이전트 방법 논문.

**builds_on 초안**: [] (근거: 본문이 딛는 것은 base LLM(ChatGPT)뿐인데 이는 백본 모델/툴로 제외. software-development methodology(SDM)는 named 시스템이 아닌 일반 방법론이라 제외. role instruction·self-collaboration은 self-정의. 명명된 선행 기법/시스템 없음.)

## 초록+서론 한글 번역
대규모 언어모델(LLM)은 뛰어난 코드 생성 능력을 보였지만 여전히 복잡한 작업에는 어려움을 겪는다. 실제 소프트웨어 개발에서 인간은 협업적 팀워크로 복잡한 작업을 처리하며, 이는 개발 복잡도를 크게 통제하고 소프트웨어 품질을 높인다. 이에 착안하여, ChatGPT를 예로 하는 LLM 기반 코드 생성용 self-collaboration 프레임워크를 제안한다. 역할지시를 통해 1) 여러 LLM 에이전트가 각기 다른 '전문가'로서 복잡한 작업 내 특정 하위작업을 담당하고, 2) 협업·상호작용 방식을 규정하여 서로 다른 역할이 가상 팀을 이루어 인간 개입 없이 협력적으로 코드 생성 작업을 해결하도록 한다. 이 가상 팀을 효과적으로 조직·관리하기 위해 소프트웨어개발방법론(SDM)을 프레임워크에 통합하고, analyst·coder·tester 세 역할로 구성된 기초 팀을 구성해 분석·코딩·테스트 단계를 담당하게 한다.

서론에서는 코드 생성이 AI·NLP·SE 분야의 주요 연구 주제이며 LLM이 큰 성과를 냈으나 복잡한 요구사항에 대한 정확한 코드 생성은 여전히 난제임을 짚는다. 인간이 복잡한 문제를 분업·상호작용·협업으로 해결하듯, 협업 팀워크는 (1) 복잡 작업을 하위작업으로 분해하고 (2) 오류 탐지·품질 관리를 돕고 (3) 요구사항과의 일관성을 보장한다. 서로 다른 모델을 학습시켜 협업시키는 방식은 비용이 크고 데이터가 부족하지만, ChatGPT 같은 LLM은 다양한 개발 단계에서 잘 작동하고 언어를 입출력 기반으로 삼아 지시·프롬프트로 인간 요구에 정렬되므로 모델 간 상호작용·협업 잠재력을 제공한다. 이에 저자들은 분업과 협업 두 부분으로 이루어진 self-collaboration 프레임워크를 제안하고, SDM을 도입해 analyst·coder·tester 세 역할의 순차적 워크플로우(각 단계가 이전 단계에 피드백)를 인스턴스화한다. 세 개의 ChatGPT 에이전트가 각 역할을 맡아 협업하며, 다수 코드 생성 벤치마크에서 단일 에이전트 대비 Pass@1을 29.9%~47.1% 상대 개선하고 저장소 수준(repository-level) 작업 같은 복잡 과제에서도 효과를 보인다.
