# 2508.13167 — Chain-of-Agents: End-to-End Agent Foundation Models via Multi-Agent Distillation and Agentic RL

**한 줄 핵심**: SOTA 다중에이전트 시스템을 단일 모델의 chain-of-agents 궤적으로 증류(multi-agent distillation)하고 에이전틱 RL로 강화하여, 한 모델 안에서 다중에이전트 협업을 종단간(end-to-end)으로 시뮬레이션하는 Agent Foundation Model(AFM).

## 초록+서론 한글 번역
LLM과 다중에이전트 시스템의 최근 발전은 심층 리서치, 바이브 코딩, 수학 추론 등 복잡한 문제해결에서 뛰어난 능력을 보였다. 그러나 대부분의 기존 다중에이전트 시스템은 정교한 에이전트 프레임워크 위에 수작업 프롬프트/워크플로 엔지니어링으로 구축되어, 계산 비효율적이고 능력이 제한되며 데이터 중심 학습의 이점을 못 누린다. 본 연구는 다중에이전트 시스템처럼(다중 도구·다중 에이전트로 다중턴 문제해결) 한 모델 안에서 종단간 복잡 문제해결을 가능케 하는 새로운 LLM 추론 패러다임 Chain-of-Agents(CoA)를 도입한다. CoA 문제해결에서 모델은 서로 다른 도구 에이전트와 역할극 에이전트를 동적으로 활성화해 다중에이전트 협업을 종단간으로 모사한다. 이 능력을 끌어내기 위해, SOTA 다중에이전트 시스템을 chain-of-agents 궤적으로 증류하는 multi-agent distillation 프레임워크로 에이전틱 SFT를 수행하고, 이어 검증 가능한 에이전틱 과제에서 에이전틱 RL로 능력을 강화한다. 결과 모델을 Agent Foundation Models(AFM)라 부른다. AFM은 웹 에이전트·코드 에이전트 세팅의 다양한 벤치마크에서 새 SOTA를 세운다. 모델 가중치·학습/평가 코드·학습 데이터를 전면 오픈소스한다.

서론: 최근 다중에이전트 시스템(MAS)은 심층 리서치·바이브 코딩 등에서 뛰어난 능력을 보였다. 이 프레임워크들은 다양한 역할·도구를 가진 여러 에이전트의 협업으로 복잡 문제를 푼다. 그러나 현재 MAS는 (1) 에이전트 간 중복 통신·정교한 워크플로 설계로 인한 높은 계산 오버헤드, (2) 상당한 재구성(프롬프트·워크플로 엔지니어링) 없이는 새 도메인·과제 일반화가 어려움, (3) 데이터 중심 학습 수행 불가라는 결정적 한계를 겪는다. (이하 원문 잘림)
