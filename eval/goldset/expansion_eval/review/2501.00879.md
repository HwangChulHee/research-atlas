# 2501.00879 — TrustRAG: Enhancing Robustness and Trustworthiness in Retrieval-Augmented Generation

**한 줄 핵심**: 말뭉치 포이즈닝 공격에 대응해, K-means 군집 필터링(1단계)과 LLM 내부지식 자기평가·충돌해소(2단계)로 악성 문서를 걸러내는 학습 불필요·플러그앤플레이 RAG 방어 프레임워크 TrustRAG 제안.

**keep/drop**: keep — RAG 신뢰성/견고성 '방어 방법' 기여(공격 논문 아님). 순수 LLM보안(공격)이 아니라 방어·신뢰성 방법이므로 keep 대상.

**builds_on 초안**: []
- ASTUTE RAG·InstructRAG·RobustRAG: 선행 RAG 방어로 그 한계("다수 악성 문서 주입 시 무력화")를 지적하나, TrustRAG는 majority-vote 기계장치 위에 얹지 않고 K-means/ROUGE라는 별도 기계장치를 제안 → 계보가 아닌 비교 baseline(D3)에 가까워 제외.
- K-means·ROUGE(부품/지표), PoisonedRAG(위협 모델·공격, 연구 대상), RAG(Lewis, 느슨한 범주 D4) 제외 → 빈 리스트.

**경계 플래그**:
- ASTUTE/InstructRAG/RobustRAG: named 선행 방어이며 D2("한계→개선")에 걸릴 수 있으나 기계장치를 딛지 않고 대체 → baseline으로 판단, 경계로 남김.
- PoisonedRAG: 방어 대상 공격(위협 모델), builds_on 아님.

## 초록+서론 한글 번역

**초록**: RAG는 외부 지식원을 통합해 LLM을 강화하지만 말뭉치 포이즈닝 공격에 취약해 성능이 크게 훼손될 수 있다. 이를 위해 우리는 생성에 검색되기 전 악성·무관 콘텐츠를 체계적으로 걸러내는 견고한 프레임워크 TrustRAG를 제안한다. 접근은 두 단계 방어다. 1단계는 잠재적 공격 패턴을 탐지하는 군집 필터링, 2단계는 LLM 내부 능력을 활용해 악성 문서를 탐지하고 불일치를 해소하는 자기평가다. TrustRAG는 어떤 오픈·클로즈드 모델과도 매끄럽게 통합되는 학습 불필요 플러그앤플레이 모듈이다. 광범위한 실험에서 검색 정확도·효율·공격 저항성의 상당한 개선을 보였다.

**서론**: RAG는 외부 지식 DB에서 정보를 동적으로 검색해 LLM의 신뢰성을 높이도록 개발되었고 ChatGPT·Bing Chat·Perplexity·Google Search AI 등에 널리 채택됐다. 그러나 최근 사례들은 심각한 약점을 드러냈다. 핵심은 RAG가 말뭉치 포이즈닝 공격에 취약하다는 근본 문제다. 검색 문서에 주입된 악성 지시가 사용자 지시를 덮어쓰거나(Greshake 등), 질의별 적대적 프롬프트가 검색기·LLM을 조작할 수 있다. 예로 PoisonedRAG는 주입된 악성 문서가 오답을 유도함을 보였다. 선행 연구는 ASTUTE RAG·InstructRAG·RobustRAG처럼 다수결과 프롬프트 설계로 잡음을 완화하는 프레임워크를 제안했으나, 공격자가 청정 문서보다 많은 악성 문서를 주입하면 무력화된다. 우리는 두 단계(Clean Retrieval, Conflict Resolution)로 작동하는 TrustRAG를 제안한다. 공격자 최적화 특성상 생성된 악성 문서가 임베딩 공간에서 촘촘히 군집되므로 K-means로 악성 그룹을 식별하고, 청정 문서를 잘못 거르지 않도록 ROUGE로 단어 중첩을 측정한다. 이후 LLM 내부 지식을 활용해 일관 정보를 재구성하고 충돌·악성·무관 문서를 걸러 최종 응답을 낸다.
