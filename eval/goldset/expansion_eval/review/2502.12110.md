# 2502.12110 — A-MEM: Agentic Memory for LLM Agents

**한 줄 핵심**: Zettelkasten 방법 원리를 따라, 새 메모리마다 구조화 노트(맥락·키워드·태그)를 생성하고 동적 인덱싱·링크·메모리 진화로 상호연결 지식망을 자율 구성하는 에이전트형 메모리 시스템 A-MEM 제안.

**keep/drop**: keep — 계보(Zettelkasten)를 가진 메모리 '방법' 기여. benchmark/survey/보안 아님.

**builds_on 초안**: ["Zettelkasten"]
- Zettelkasten: 본문 "Following the basic principles of the Zettelkasten method, we designed our memory system" / "draws inspiration from the Zettelkasten method" — 명시적으로 딛고 설계한 named 지식관리 패러다임(D2/lineage).

**경계 플래그**:
- Mem0: 선행 메모리 시스템으로 그 한계(그래프 DB의 고정 스키마 경직성)를 지적하나(D2), A-MEM은 그래프 DB 기계장치를 딛지 않고 동적 링킹으로 대체 → baseline/한계-대상으로 판단, builds_on 제외(경계).
- RAG(Mem0가 따른 원리)는 A-MEM의 계보 아님, 느슨한 범주(D4) 제외.

## 초록+서론 한글 번역

**초록**: LLM 에이전트는 외부 도구를 잘 쓰지만 과거 경험을 활용하려면 메모리 시스템이 필요하다. 현재 메모리 시스템은 기본 저장·검색은 되나 정교한 메모리 조직이 부족하며, 최근 그래프 DB 도입 시도에도 고정된 연산·구조가 다양한 과제로의 적응성을 제한한다. 이를 위해 본 논문은 메모리를 에이전트적으로 동적 조직하는 새 에이전트형 메모리 시스템을 제안한다. Zettelkasten 방법의 기본 원리를 따라, 동적 인덱싱·링킹으로 상호연결된 지식망을 만든다. 새 메모리 추가 시 맥락 서술·키워드·태그 등 구조화 속성을 담은 포괄적 노트를 생성하고, 과거 메모리를 분석해 의미 있는 유사성이 있으면 링크를 맺는다. 나아가 새 메모리가 통합되면 기존 메모리의 맥락 표현·속성 갱신을 촉발하는 '메모리 진화'가 가능해, 메모리망이 이해를 지속적으로 정련한다. 여섯 파운데이션 모델 실험에서 기존 SOTA baseline 대비 우수한 개선을 보였다.

**서론**: LLM 에이전트는 환경과 상호작용하고 과제를 수행·의사결정하는 능력을 보였다. 강한 추론에도 외부 환경과의 장기 상호작용을 위해선 메모리 시스템이 필요하다. 기존 메모리 시스템은 기본 저장 기능을 제공하되 개발자가 저장 구조·저장 지점·검색 시점을 미리 정의해야 한다. 구조화 조직을 위해 Mem0는 RAG 원리를 따라 그래프 DB를 도입하지만, 사전 정의된 스키마·관계 의존성이 근본적으로 적응성을 제한한다. 예컨대 새로운 수학 해법을 배울 때 기존 시스템은 미리 설정된 틀 안에서만 분류·연결할 뿐 새 조직 패턴을 만들지 못한다. 이에 우리는 정적·사전결정 메모리 연산에 의존하지 않고 동적 메모리 구조화를 가능케 하는 새 에이전트형 메모리 시스템 A-MEM을 소개한다. 원자적 노트와 유연한 링킹으로 상호연결 정보망을 만드는 Zettelkasten 방법에서 영감을 받는다. 기여: (1) 맥락 서술 자동 생성·동적 링크 확립·메모리 진화가 가능한 A-MEM, (2) 링크 생성과 메모리 진화를 촉발하는 갱신 메커니즘, (3) 장기 대화 데이터셋·여섯 모델·여섯 지표의 종합 평가.
