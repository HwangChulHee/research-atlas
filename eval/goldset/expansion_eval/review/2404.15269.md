# 2404.15269 — Aligning LLM Agents by Learning Latent Preference from User Edits

**한 줄 핵심**: 사용자의 응답 편집을 자연 발생 피드백으로 삼아, 파인튜닝 없이 잠재 선호를 서술형으로 추론(PRELUDE)하고 k-근접 맥락에서 선호를 검색·집계해 프롬프트를 구성하는 알고리즘 CIPHER 제안.

**keep/drop**: keep — 사용자 편집 기반 에이전트 정렬(신뢰성/개인화) '방법' 기여. benchmark/survey/보안공격 아님.

**builds_on 초안**: []
- CIPHER는 k-근접 맥락에서 추론 선호를 검색·집계하는 검색기반 in-context 방식이나, 딛고 확장한 '고유명사 named 기법'이 본문에 명시되지 않음.
- RLHF는 D1(정렬/옵티마이저) 및 대비 baseline이라 제외.

**경계 플래그**:
- 검색기반 ICL 패러다임에 기대나 구체 named 선행 기법 없음 → builds_on 비움.
- 정렬/개인화 방법으로, 순수 '평가/신뢰성 방법'보다는 에이전트 정렬 방법에 가까움(스코프 경계).

## 초록+서론 한글 번역

**초록**: 우리는 에이전트 출력에 대한 사용자의 편집을 바탕으로 LLM 기반 언어 에이전트를 상호작용적으로 학습시키는 문제를 다룬다. 쓰기 보조 같은 전형적 설정에서 사용자는 에이전트와 상호작용해 응답을 생성하고, 정확성 개선뿐 아니라 잠재 선호에 맞춰 개인화하기 위해 응답을 편집할 수 있다. 편집 피드백은 자연스럽게 생성되므로 사용자 선호와의 정렬 개선, 시간에 따른 편집 비용 절감에 적합하다. 우리는 과거 편집 데이터로 사용자의 잠재 선호 서술을 추론하는 학습 프레임워크 PRELUDE를 제안한다. 추론된 선호 서술은 향후 응답 생성용 프롬프트 정의에 쓰여, 비용이 크고 확장이 어려우며 다른 과제 성능을 저하시킬 수 있는 파인튜닝을 피한다. 또한 서술형 선호 학습은 해석성을 높여 사용자가 학습된 선호를 보고 수정할 수 있게 한다. 선호는 복잡·미묘·맥락 의존적이라 학습이 어렵다. 이를 위해 LLM을 활용해 주어진 맥락에서 편집으로부터 사용자 선호를 추론하는 간단·효과적 알고리즘 CIPHER를 제안한다. CIPHER는 이력의 k-근접 맥락에서 추론된 선호를 검색해 응답 생성용 집계 선호를 형성한다. 요약과 이메일 쓰기 두 상호작용 환경을 도입하고 GPT-4 시뮬레이션 사용자로 평가했으며, CIPHER는 최저 편집거리 비용으로 여러 baseline을 능가했다.

**서론**: LLM 기반 언어 에이전트는 다양한 응용에 개발되어 왔으나, 뛰어난 제로샷 성능에도 특정 사용자·과제에 정렬될 필요가 있다. 많은 응용에서 자연스러운 피드백은 사용자 편집이다—사용자가 에이전트에 질의하고, 최종 사용 전 응답을 편집한다. 반면 RLHF의 비교 기반 선호 피드백은 주석자에게 모델 응답을 제시해 순위를 매기게 하는 명시적 수집이라 비싸다. 이 관찰에 착안해 사용자 편집을 피드백으로 하는 상호작용 학습에 집중한다. 사용자가 쓰기 보조 에이전트와 상호작용해 과제를 완료하는 시나리오를 상정한다.
