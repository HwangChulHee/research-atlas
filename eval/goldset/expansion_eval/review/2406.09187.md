# 2406.09187 — GuardAgent: Safeguard LLM Agents by a Guard Agent via Knowledge-Enabled Reasoning

**한 줄 핵심**: 타깃 에이전트의 행동이 안전 가드 요구를 만족하는지, 지식기반 추론으로 행동 계획→가드레일 코드를 생성·실행해 결정론적으로 검사하는 최초의 가드레일 에이전트.

**keep/drop**: keep — LLM 에이전트 안전성의 '방어/가드레일 방법' 논문. 공격 논문이 아니라 신뢰성 방어 방법이므로 순수 LLM보안(공격) drop 대상 아님.

**builds_on 초안**: []
- LLM guardrails 패러다임을 에이전트로 확장(D2 성격)하나, "guardrail"은 범주어(D4 제외).
- 구체 명명 기법(Llama Guard, NeMo Guardrails 등)은 인용만 되고 본문 명칭으로 등장하지 않음.
- in-context learning + 메모리 검색 데모(부품)를 활용하나 딛고·확장한 명명 기법 아님.
- 딛고·확장한 명명된 선행 기법 없음 → 빈 리스트.

**경계 플래그**:
- "기존 LLM 가드레일은 에이전트의 광범위한 출력·요구를 다루지 못함 → 그 위에서 에이전트용으로 확장"이라는 D2형 서사가 있으나, 계보 대상이 범주어(guardrails)라 명명 기법으로 채택하지 않음.

## 초록+서론 한글 번역
LLM 에이전트의 급성장으로 안전·보안 우려가 커졌는데, 텍스트 유해성 중심의 기존 LLM 가드레일로는 이를 다룰 수 없다. 저자들은 GuardAgent를 제안한다. 이는 타깃 에이전트를 보호하는 최초의 가드레일 에이전트로, 에이전트의 행동이 주어진 안전 가드 요구를 만족하는지 동적으로 검사한다. GuardAgent는 먼저 안전 가드 요구를 분석해 과제 계획을 세우고, 이를 가드레일 코드로 변환해 실행함으로써 결정론적으로 요구를 따른다. 두 단계 모두에서 LLM을 추론 요소로 쓰되, 과거 과제 경험을 저장한 메모리 모듈에서 검색한 in-context 데모로 보완한다(지식기반 추론). 하드코딩된 기존 안전장치와 달리 새 타깃 에이전트에 함수만 추가해 적응할 수 있고, 자연어 기반 가드레일보다 코드 생성·실행이 더 신뢰할 수 있으며, 추가 학습 없이 off-the-shelf LLM을 쓴다. 또한 헬스케어 에이전트의 접근 제어를 평가하는 EICU-AC와 웹 에이전트 안전정책을 평가하는 Mind2Web-SC 벤치마크를 새로 제안하며, 각각 98%·83% 이상의 가드레일 정확도를 보인다.
