## 초록+서론 한글 번역
LLM은 AI를 혁신했으나 제한된 컨텍스트 윈도우 때문에 긴 대화나 문서 분석에 한계가 있다. 이를 넘어서기 위해 저자들은 가상 컨텍스트 관리(virtual context management)를 제안한다. 이는 전통적 OS의 계층적 메모리(물리 메모리와 디스크 사이 페이징으로 확장 가상메모리의 착시를 주는 것)에서 영감을 받았다. 이 기법으로 MemGPT를 소개하는데, 서로 다른 저장 계층을 지능적으로 관리해 LLM의 제한된 컨텍스트 안에서 확장된 컨텍스트를 제공한다. 트랜스포머의 self-attention은 컨텍스트 길이를 직접 늘릴 때 계산·메모리 비용이 제곱으로 증가하고, 긴 컨텍스트 모델도 추가 컨텍스트를 효과적으로 활용하지 못한다는 연구가 있어 대안 기법이 필요하다. MemGPT는 LLM 에이전트의 function calling 능력을 활용해, 에이전트가 외부 저장소를 읽고 쓰며 자신의 컨텍스트를 수정하고 언제 응답할지 선택하게 한다. 즉 컨텍스트 윈도우('메인 메모리')와 외부 저장소 사이로 정보를 '페이징'하고, 이벤트 기반 제어 흐름으로 컨텍스트 관리·응답 생성·사용자 상호작용을 조율한다. 문서 분석과 멀티세션 대화 두 영역에서 유한 컨텍스트 모델로도 무한 컨텍스트를 다룰 수 있음을 보인다.
